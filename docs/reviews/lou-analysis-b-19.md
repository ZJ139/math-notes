## 数学复核

B127 用连续的高斯原函数作比较，通过中值定理推出差值控制；不对可能不连续的 f′ 直接积分。核对尾积分中的 1/(2x)、端点 x=1、M=0 及非零常值反例。复值情形另外以实投影说明。

B128 先由有界性和介值定理得到唯一不动点，再以距离极限和聚点排除正的极限距离。B129 重新求导核对 x+π/2−arctan x 的导数为 x²/(1+x²)，且位移始终正；用单调有界反证排除所有有限极限。补充说明在一维中已有不动点便能自动控制轨道。

B130 沿线段投影为实函数，避免伪用向量值中值等式；位移函数在不变闭球上取得最小值，严格缩距强迫最小值为零。核查任意初值、提前到达不动点及有限维紧致性的用途。

B131 对 0<α<1 取 β=(1−α)/(2α)>0，核对 Hölder 的共轭指数、权重指数 −1/2，以及最终 n^(−1−β) 与尾和 k^(−β) 的抵消。仅在有限双重和上换序，再用单调有界性取极限。α<0 时使用 t^(2α) 的凸性并在取负次幂时反向不等号；α=0 单列几何平均；α=1 用 2^(−n) 给出边界反例。常数明确不声称最优。

B132 减去候选切平面后，坐标轴上的余项均为 o(|t|)；有限个坐标选择共同邻域，再以坐标凸组合得到上界，以 h 和 −h 的中点关系得到下界。没有将方向上的点态收敛直接当作方向一致收敛。

B133 用有界极小化序列、闭性和中点平方恒等式证明最近点存在唯一。沿可行线段在左端点取最小值，使用 F′₊(0)≥0；反向平方展开证明不等式的充分性。明确指出若省去 x∈E，x=x₀ 也满足不等式，故无约束唯一性不成立。题册未附题图，论证不依赖图形。
