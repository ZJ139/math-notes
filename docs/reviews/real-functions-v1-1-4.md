## 数学复核

共十个小目，16 条连续编号的命题或定理、7 个例子、8 道完整解答练习、22 个连续且唯一的编号公式。逐条核对陈述、前提、证明及内部引用。

- 可数基中明确选取有理中心和半径的不等式；Lindelöf 只得到可数子覆盖，不混同紧性。空集和通常选择公理框架已说明。
- 构成区间存在性从含固定点的区间之并得到，唯一性用极大性与端点反证；允许无穷端点。余区间的有限端点属于边界，端点只在边界中稠密；两个余区间共享端点恰对应闭集的孤立点。
- 高维分解采用嵌套二进半开格子，保证公共面的唯一归属；第一次符合闭包包含条件即选中，后代不重复选取。覆盖性用直径 √n·2⁻ᵏ 趋零，不将这些方体误称为开块，也不宣称唯一分解。
- Cantor 集先由闭集、有界性和端点逼近证明紧、完美、空内部；三进制使用“存在一个仅含 0、2 的表示”。首个不同位减尾和严格为正，证明代码单射；明确三进制代码转二进制实数的映射并非单射。
- 任意小总长度开覆盖先延长有限保留区间，不提前使用尚未定义的测度。端点可数且稠密与 Cantor 集不可数不矛盾。
- 一般非空完全集的连续统基数使用二叉闭球构造：子球互不相交、在父球内部、中心留在集合中、直径趋零，结合闭集套定理。
- 凝聚点与普通聚点区分；利用可数基证明非凝聚部分可数，再证明凝聚点集闭且无孤立点。闭集分解使用凝聚点集作为最大完美核，并补足唯一性证明。可数余部不必在原集合中全部孤立，给出含 1/k 与 0 的反例。
- Fσ、Gδ 的封闭运算区分有限与可数；用到闭集的距离时单独处理空集，全空间的紧耗尽也另行处理。相对 Borel 族等式不要求子空间自身 Borel。
- Borel 基数上界采用无无限分支的可数运算树，先验证赋值唯一及有效代码根值对补、可数并封闭，再计数；不把一次可数运算或有限运算深度误作全部 Borel 构造。
- 教材原题 1/4、1/13 的三进制周期表示分别由几何级数验证；C+C=[0,2] 使用有界余数递推与数字 0、2、4 拆分，避开无说明的进位。
