## 数学复核

- B289：用弧长参数统一证明线性、可加、保序、中值、Hölder、一致收敛积分交换及反向不变。中值点要求实值连续与连通；积分为零的逐点结论要求非负连续；重复遍历需按重数计入。
- B290：先正交旋转，再用等高参数，其两个切向量正交且长度乘积为一；遗漏极点及接缝面积为零。先对绝对值证明复合函数可积，后用 Fubini。A>0 时等价类代表元不影响结果；A=0 时须有明确有限点值 f(0)，两边均为 4πf(0)，不把退化区间的 L¹ 等价类当作确定的点值。
- B291：固定相位 λ=共轭 I/|I| 后取实部，再逐点比较，直接证明积分模估计。短弦/短弧之比只在正则弧长参数点使用；一般 C¹ 参数曲线的模估计无须处处正则。等号条件是 λfT 几乎处处非负实数。
- B292：给出紧、可定向、分片 C¹ 正则、有限面积与连续 P 的充分条件；通过 Pν₁dS 定义，并证明有向参数变换下的不变性。推广到 |Pν₁| 可积；无需闭曲面、全局单一图形或 P 可微。自交需明确曲面分片及重数。
- B293：外法向量为 (x/a²,y/b²,z/c²)/H，椭球方程使被积式等于反平方场 (x,y,z)/r³ 的通量。挖去半径 ε<min(a,b,c) 的小球，内边界法向反向，Gauss 公式将积分化为小球通量 4π。没有在含奇点的整个区域错误使用散度为零。
- B294：明确 Du 的下标及余子式矩阵定义。用排列交换 σ(i) 与 σ(l)，逐项配对证明 Piola 恒等式；混合偏导相等、排列符号相反。J(t)=∫det(A+tDφ) 为多项式，其导数是紧支向量场的散度，故为零。证明允许 A 奇异及 Jacobian 变号。另说明 C² 闭包零边界解释也适用；绝对行列式版本一般错误。
- B295：环域 Green 公式给任意半径圆周的积分相同；无穷远条件提供所有方向统一的 R≥c₀r²ⁿ，下界与分子次数相配给系数 O(r⁻²)。乘以圆周长度得到周期 O(r⁻¹)→0。只用闭性不能在穿孔平面断言周期为零，正文给出角形式反例辨析。

符号计算仅为交叉检查，不替代证明：三维非线性多项式映射 u=(x²y+yz,y²z+xz,z²x+xy) 的余子式逐行散度均为零。在单位方形取 b=x²(1−x)²y²(1−y)²、φ=(b,(x−1/2)b)，分别令 A=[[1,2],[2,4]] 与 [[2,1],[−1,3]]，精确积分 det(A+tDφ) 分别恒为 0 与 7，与 det A 一致。
