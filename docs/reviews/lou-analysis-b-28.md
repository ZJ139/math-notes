## 数学复核

- B191：每轮删除长度合法；剩余分支长度趋零，故闭集无内点。删除总长 1/2。距离函数连续且零集恰为该闭集；每个开区间包含距离严格为正的小区间，故积分函数严格单增。定义域为整个实轴。
- B192：中心化幂是首一 n 次多项式，低阶矩全部消去。零阶矩和非零的 n 阶矩保证函数兼取正、负值，进而有内部零点及正长度的严格缺口，从而证明严格不等号。没有把非严格积分估计直接写成严格结论。
- B193：不额外假设零阶三角矩。若少于 2n 个零点，则变号点数 m≤2n−1。半角代换后的正根多项式 q 的偶次系数同号，tq 的偶次系数同为相反号；两个带偶权的全实轴积分绝对收敛，均非零。选 λ=−A/B>0，给 q 增加一个负根，消去对应三角多项式的常数项。次数至多 2n 的分子除以 (1+t²)ⁿ 恰为频率不超过 n 的三角多项式；在正半轴没有额外零点。乘积同号、局部严格为正与正交矛盾。有限个不变号零点不影响论证，无穷零点情形单独处理。
- B194：最大点可以在端点。邻域外紧集的最大值 m 严格小于 M；选 m<q<M，并由连续性获得正长度的分母下界。远处用 L¹ 范数而非全局上界控制可积因子，故涵盖无界的 Lebesgue 可积函数。
- B195：分部积分两端边界项皆为零，得到 I_n=J_(n+1)/(n+1)。用相同归一化积分分别处理 sin x 与 x sin x，最终保留 n/(n+1) 系数。
- B196：整体换元 u=(1−x/2)(1−x/4) 在 [0,1] 严格递减，端点 1 与 3/8；反函数 x=3−√(1+8u)，Jacobian 为 −4/√(1+8u)。集中定理作用于固定连续因子，归一化常数比为 1/2，极限为 2/3。
- B197：四组转化都有完整推导。一般 Cauchy 公式另外用辅助函数处理，不与要求导数非零的比值形式混淆。Taylor 积分余项给出分部积分递推。用显式无界导数例子说明 C¹ 是积分证明的充分条件而不是微分中值定理的必要条件，用变号权反例说明带权平均值的限制。
