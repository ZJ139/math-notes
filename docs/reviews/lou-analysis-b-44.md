## 证明复核

- B303：每个卷积由 L¹×L∞ 绝对可积。将误差 h 在原点邻域与补集分开，再以 K 截断 h，得到尾部上界 Kη_n(δ)+C_δ∫_{|h|>K}|h|。极限顺序 n、K、ε 正确。连续周期函数有界且一致连续，第二问不需 C_δ。
- B304：Minkowski 与 Lp 平移连续性证明范数逼近，p=2 单独解释为均方收敛。跳跃函数在宽 1/n 的邻域有本性上确界误差至少 1/2。远端尖峰反例中区间长 2^{-3n}、函数高 2^n、核高 2^{2n}，核尾质量为 2^{-n}，卷积值恒为 1；每个核本身仍有界，精确定位缺失的统一条件。没有声称所有 L¹ 连续点或所有 L∞ 函数都能逼近。
- B305：正交积分系数为 π/4，交替平方倒数和为 −π²/12；所得 I=π²ln²2/8−π⁴/192。独立数值积分为 0.0853961317833699293065612690068，与闭式相差小于 5×10^{-32}。数值只交叉检查，证明不依赖数值。
- B306：补齐 a₀、a₁使前两个二阶差分为零，其余由 (1/ln t)''>0 保证正性。望远镜公式的余项 a_{N+1}+(N+1−j)d_{N+1} 趋零；核组合的 L¹ 范数总和有限，Tonelli 与 Fourier 系数提取分别有非负性、L¹ 收敛作为依据。用 B303 识别核组合与普通级数在非零点的和，避免未经论证地把给定数列当作 Fourier 系数。二阶差分的积分表示证明 H(x)→∞；Bessel 不等式排除 L²。原函数均值为零。
- B307：小端估计为 δ^{1−α}/(1−α)，大端经 Abel 求和为 C A^{−α}，均与 x 无关。Gamma-Laplace 公式在右半平面取主值，Abel 阻尼极限的尾界对阻尼参数统一。正弦常数 Γ(1−α)cos(πα/2)，余弦常数 Γ(1−α)sin(πα/2)。以 α=1/4、1/2、3/4 的 polylog 数值作辅助核对，均符合推导；端点 α=0,1 未纳入。
- B308：b_n=1/(n ln(n+1)) 单调且 nb_n→0；调用 B309（其证明独立于 B308），无循环论证。原函数在周期两端均为零，逐项积分由一致收敛保证。Fejér 平均零点值至少为前半段系数和的一半，发散，而有界函数的正核平均必受其范数约束。不能据普通 Fourier 级数在一点发散否定连续性这一陷阱已明示。
- B309：取 x_m=π/(4m)，整段 m≤n≤2m 的正弦至少为 1/√2，得到 mb_{2m}→0，再用单调性处理奇数。充分性对 K=⌊1/x⌋分段，统一尾界为 (1+π) sup_{n≥p} n b_n；空和、x=0、负 x、x=π 均覆盖。
