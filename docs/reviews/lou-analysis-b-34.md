## 数学专项复核

- **B233：** 交换级数的充要检查点为 `|h|<x0-1`，以 `Σ_n n^{-(x0-|h|)}` 支配全部指数展开绝对值；由 x↓1 的发散得到 Taylor 收敛半径恰为 `x0-1`。
- **B234：** 假设系数级数在边界收敛，Abel 分部求和得到 Stolz 区域有界；取 `z=1-t-it`，复正弦增长为 `exp(1/(2t))`，任何固定有限阶 `(1-z)^m` 都不能抵消，故一切 n≥1 均不收敛。未混淆实轴趋零和复平面本性奇点。
- **B235：** 实 Taylor 级数复化，并由圆盘交集含实开区间与恒等定理确认局部定义一致；其并域连通。无需统一正半径。
- **B236：** 对每个紧区间、每个固定阶 k，统一导数界为 `C_k n^k L^n/n!`，由 M 判别与逐项求导定理得到 `C∞`；在 0 处截断恒等于 1，逐项读出所需数据。给定形式系数 c_n 时需选择 a_n=n!c_n。
- **B237：** 交错对数余项除以 x 后在 [0,1] 统一趋零；得到 `Σ(-1)^{n-1}/n² = π²/12`。已数值复核与高精度积分一致。
- **B238：** 六种互不重复的两因子敛散组合全部列出；A+A 与 A+C 由绝对和估计、Mertens 定理约束，余下每种结果均有构造。特别对“C+C→A”给出实系数显式反例以及裂平面的钥匙孔积分证明，避免误以为不可能；其前 160 阶系数数值检查与预期收敛方向一致。
- **B239：** 第一问将截断点 n 与 `r_n=1-1/n` 对齐，显式界出头部、尾部；第二问验证 Cesàro 生成函数的归一化积分核，以第一问推出充分性，并检验必要性。
