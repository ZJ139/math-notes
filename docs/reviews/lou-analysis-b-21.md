## 数学复核

B141 按函数值与去心极限的差分层。固定层后，在邻点的去心极限中避开中心点，以两次估计证明该层离散，再用有理端点区间单射编码。没有把所有不连续点直接断言为离散集；以稠密的可去间断点函数作辨析。允许广义极限时用 arctan 化归有限极限。

B142 先排除原多项式根，设 H=G/g=g−g'/g。仅在 H 的零点处证明 H'>0，不误称 H 全局递增。零点有限性与介值定理给出每个极点间区间至多一根，再依照极点与无穷远符号逐区间精确计数；验证所有新根均为单根、m=1 仍适用。负首项系数和重根的反例已逐式核对。

B143 使用双侧下极限给出的严格局部次序，通过上确界推进证明全局严格递增；整个证明不使用连续性或最值定理。非负情形加 εx 再令 ε 趋零。向上跳跃例的左右差商下极限确为 1，常值函数排除弱条件下的严格递增。

B144 先证明分母为正。最佳候选为 2，导数恒等式为 (1−c)²(2c+1)/c²，其中 c=cos x。全区间严格下界与 0 处 Taylor 极限分别证明；下确界不取到，提示的可行常数恰为 α≤2。

B145 连续性用于闭子区间上取最大值。若图像超过弦线，加入 ε(x−u)(x−v)，以足够小的 ε 保留正内部最大值，而对称二阶差商增加 2ε，产生矛盾。平方正部函数在 0 的对称二阶导数为 1、普通二阶导数不存在，明确两种概念不同。

B146 原题命题成立。同一二次扰动证明直接用于下极限，涵盖正无穷，不假定差商逐项非负。|x| 说明正无穷必须允许；单点下凹函数说明连续性不能省略。

B147 给出四组探究：连续函数的左右下 Dini 判别；凸函数的有限左右导数及割线次序和逆命题；广义二阶差商一致下界与减去 cx²/2 后凸性的等价及定量弦线间隙；量词、连续性与严格性的反例。单侧判别在闭子区间上明确只需相应方向的内侧端点导数。普通二阶导数与对称二阶导数的联系由 Cauchy 中值定理证明 Peano 展开，无隐含 C² 假设。−|x| 表明遗漏一个点也会破坏凸性；x⁴ 说明严格凸不要求二阶导数处处正。
