## 数学校审

- 有限测度情形在同一紧集上同时保留简单函数的连续性和一致收敛。一般情形使用半开单位立方体的局部有限分割，验证紧核之并闭及拼接连续性。
- 连续延拓保留函数在大闭集上的原值。严格界由距离因子保证；有限测度时可在紧核外截断。实线常函数给出紧支逼近在无限测度上的限制。
- 差异集测度可求和保证几乎处处最终相等。于全空间使用 Cauchy 点集构造处处有限的 Borel 代表，避免在任意 Lebesgue 可测定义域的边界直接拼接。Dirichlet 函数的处处逼近障碍用 Baire 定理证明。
- 在可测可加、中点凸两例中分别展开差集与反射交集的论证。Hamel 系数函数共用同一反例，同时解释严格中点不等式的情形。
- 教材例 3.2.7—3.2.10 分别对应开集原像判别、连续外函数复合、Cantor 函数诱导的反例及零集原像条件。反例中明确内外函数的顺序，以及所取不可测子集所在的正测度紧集。
