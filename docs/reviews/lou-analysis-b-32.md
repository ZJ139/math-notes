## 数学复核

- B219：只在 f' 非零的局部使用中值定理和 Lipschitz 逆；证明 Lipschitz 映射保零测性，再由有理区间基获得可列覆盖。处理端点、退化区间与常值像，不假设全局单调，不混淆像与原像。
- B220：正向固定含指定点的单一邻域及单一部分和，再作三项估计；反向先逐点取尾和，再用尾和连续性和紧性。明确各尾部位置随邻域变化，不能用最大位置推出一致收敛。
- B221：紧子集上的开球覆盖证明完整；全空间采用局部条件。以逐渐扩大的紧支截断、望远镜级数构造连续极限而无法有限覆盖全空间的反例。
- B222：(i) 用有理值域区间基；(ii) 选择内缩幅度后取逐点尾部；(iii) 用闭集 C 减去整个原像的内部得到闭的无处稠密集；(iv) 提供嵌套闭球的 Baire 论证，得连续点稠密且为 G-delta 集。未把一般差集直接称为无处稠密。
- B223：连续正步长保证差商不越界，差商连续且逐点趋于导函数；引用已经证明的开集版本。补充无穷端点，未偷加导函数有界、连续或一致收敛。
- B224：有界方向望远镜估计；无界方向取对数并比较相对增量，利用 -log(1-r) <= 2r 的尾部估计排除收敛，不假设相邻比值趋一。e^(2^n) 反驳替换分母后的必要性，e^n 说明新级数也可发散。
- B225：六项分别检查一致收敛量词、Riemann 极限可积性、控制收敛的可积控制、导函数一致收敛与基点值、联合可测及绝对可积、差商的共同控制、混合二阶偏导的连续性。给出六类失效示例。尖峰用 30u²(1-u)² 零延拓，确保它本身 C1，参数微分反例各截面也 C1；没有用不可导尖峰冒充反例。
- 符号计算辅助核对：尖峰积分恰为 1、两端导数均为 0；积分换序反例的两个原函数恒等式；混合偏导反例轴上导数为 x 与 -y。该核对只是计算辅助，正文中的推理与条件检查独立成立。
