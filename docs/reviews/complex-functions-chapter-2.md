## 证明覆盖与逻辑依赖

| 节 | 主要结论与复核要点 |
| --- | --- |
| 2.1 | 复可微的增量式、连续性、单点可微与邻域全纯之别、和积商及链式法则；全部给出证明 |
| 2.2 | 实线性主部、Wirtinger 算子、实可微加 Cauchy–Riemann 方程的充要性、C¹ 充分条件与反例、Laplace 分解、调和与共轭调和 |
| 2.3 | 有向角与转动角、非零导数的保角性和伸缩率、Jacobian、局部逆；区分局部保角与全局单叶 |
| 2.4 | 指数、对数、幂与三角函数的编号性质，单叶域、割线和分支；代数根式的绕数判据及零极点条件；例 2.4.5—2.4.9 的完整构造 |
| 2.5 | 分式线性变换的逆与群结构、球面局部坐标、保圆、交比与三点构造、左右侧、对称点、半平面及圆盘变换、偏心圆环归一化 |

教材在第二章预引全纯函数的高阶正则性。本章以 Goursat 套三角形论证建立局部积分引理，再在正方形上推出 Cauchy 积分表示及全部连续偏导，不预设导数连续、调和性或幂级数展开。调和性与实逆函数定理的使用因而有独立依据。

全局共轭调和函数从闭合实微分形式构造，补出单连通域的路径无关性理由。全纯对数由调和函数 log|z| 的共轭构造，不把主辐角加常数误当任意单连通域上的连续辐角。根式分支用闭路绕数判据证明，并说明一般闭路到简单多边形闭路的归约。圆盘变换只证明分式线性变换的分类，不提前冒称已证明所有全纯自同构的分类。

## 校勘与条件

正文按正确条件陈述，并注明与教材简写的区别；习题保留原题，疑义另列，不静默改题。

- 例 2.4.5、2.4.6 的割缝须删去端点，所称集合才是开域。
- 定理 2.4.7 区分支点、零点和极点；根式在域内的零极点须另检查可延拓条件。例 2.4.9 的 -1 仍须作为极点排除。
- 定理 2.5.4 的目标三点也必须互异；定理 2.5.6 的归一化证明要求后三点互异，不能覆盖任意重复模式。
- 习题 2.2.12、2.2.14 分别注明 f/φ、U/u 的记号问题；2.2.13 注明复合所需的二阶正则性与非常数条件。
- 习题 2.4.10 原式的共轭复幂在一般复指数下须同时共轭指数。
- 习题 2.4.12(2) 原式加法应为乘法；2.4.17(1) 的任意平移宽 π 带状域不能保证单叶。
- 习题 2.5.9 注明非退化圆的实系数条件及无穷远解释；2.5.11 原式分母 cx+d 的 x 应为 z。
