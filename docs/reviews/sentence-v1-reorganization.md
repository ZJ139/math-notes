# 长难句原句恢复与结构整理

2026-10-25按用户要求重新整理长难句板块，保留74个独立条目的路径、编号和分类。原句此前没有出现在条目中，页面只有题源评论与原创训练，导致无法直接对照学习。

## 原句与出处

从仓库已经收录的10个年份试卷PDF中定位37篇阅读，恢复74条原句。每条英文经过空白归一化后的SHA-256均与既有 `scripts/fixtures/sentence-v1-source.json` 中的 `originalSentenceSha256` 一致。未以原创练习代替题源，也未将完整试卷转换为新增网页正文。

处理了PDF抽取产生的换行、连字符、撇号空格、引号样式与破折号缺失；F20的两年半恢复为 `2½`。这些恢复同样通过既有原句散列校验。L32保留句库原有的引用范围，至 `reproduced.` 结束。

每条原句下面列明年份、Text、自然段与句库编号，并链接到已有试卷 `/files/english/exams/{year}英一.pdf#page={page}`。10个年份的Text 1—4均在现有横版试卷的第2—5页；实际页眉经读取核对。P标记仍指文章自然段，不混用PDF页码。既有试卷与附件字节未修改。

## 学习内容

每条固定五个二级标题：原句、句子拆解、句子直译、重要单词、原创拓展。

- 原句置于第一节，并在Text目录与搜索列表中完整展示。
- 拆解先给主干读法，再分点说明从句、修饰语、指代及逻辑范围。主干读法明确标注可能省略修饰或还原语序。
- 逐条补写中文直译，保留否定、条件、比较、可能性及观点归属。
- 每条整理3—5个语境词汇或表达，突出熟词僻义与固定搭配。
- 原有独立情境训练、训练译文和训练拆解移到原创拓展；考场提示保留已复核版本。
- 总目录新增8组原创对照练习：否定范围、条件方向、最低证据范围、非万能与无效、倒装主语、推论限制、事实与预测、命题指代。

删除条目中重复的通用低词汇量段落与重复导航；通用阅读步骤保留在总目录。原有语法修正及全部旧条目地址继续有效。

## 界面与回归覆盖

复用现有静态页面、年份与Text导航、全文搜索，不新增客户端请求或状态。原句预览只读取明确标为“原句”的区块；只有原创练习或缺少原句的材料不会误显示训练句。Text目录提供五部分的直达锚点。

回归测试逐条校验原句散列、章节顺序、译文与词汇存在性、原文上下文链接、训练与原句区分、目录预览、英文原句搜索和既有语法修正。页面结构仍使用语义化标题、引用块、表格与导航；纯白背景和现有字体保持一致。
