## 数学复核

- B184：选择 x sin(π/x)，以振幅趋零证明原点连续；正值集精确为 (1/(2k+1),1/(2k))，k≥1。对任意 k>j，负区间 (1/(2k),1/(2k−1)) 位于两个正区间之间，显式取 ξ=1/(2k−1/2)。
- B185：每轮删去 2^(n−1) 个长度 4^(−n) 的中间区间；剩余分支长度 L_n=2^(−n−1)+2^(−2n−1)，确保操作合法且内点为空。删去总长度 1/2，闭集测度 1/2。距离函数为 1-Lipschitz，外函数仅在端点不连续，复合为该闭集的指标函数。上下和直接相差至少 (b−a)/2；同时处理区间退化时反例不存在。
- B186：取 f=1−dist，严格保留原题阈值处的“≥”及等号；截断恰为指标函数，不连续点恰为正测度闭疏朗集。
- B187：奇、偶轮删除的间隙均逼近 K 的每一点。上方横条连接全部竖直通道，证明开集道路连通后才取闭包。另一组开间隙与前一组闭包不交，保证 K×(0,1) 在闭包边界上。Tonelli 用于非负可测指标函数，得边界面积至少 1/2。没有把任意闭集误当闭区域。
- B188：零延拓到长方体；用任意小 Darboux 上和覆盖固定高度水平集，先证其外测度零，不预设其可测性。非负性给出非零点集为这些水平集的可列并。反例在枚举有理点上赋值 1/j，无理点为零；有限个大值点的小区间覆盖控制上和，所有下和为零。非零点集为稠密可列集，边界整个区间；明确区分非零点集与拓扑支集。
- B189：截断函数 η 的两端函数值和导数拼接相同，|η′|≤18。每个补区间两端使用 t²sin(1/t)，两个活跃支集不交。|F(x)|≤dist(x,K)² 推出 K 上导数为零；活跃项导数≤18t²/ℓ+1+2t≤11/3，统一适用于全部间隙。t=1/(2πm) 给端点附近导数 −1 或 1；间隙端点逼近 K 的任意点，故导数在正测度集合上不连续。伸缩到任意非退化区间，另给两端零延拓以满足双侧可导解释。
- B190：选正系数 2^(−n) 与奇性 |x−q_n|^(−1/2)。每项积分≤2√2，部分和非负单增，故单调收敛合法且总积分有限，无穷点集零测度。固定 j 用单项下界控制整个删心邻域，量词是所有 x，而非几乎所有 x。处处有限实值版本的不可能性由开稠密高值集及闭区间套证明；零测集上的重新赋值不能保持全部普通极限。不将此取值约定问题隐去。
