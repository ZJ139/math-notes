## 证明覆盖与逻辑复核

| 节 | 主要内容及证明要点 |
| --- | --- |
| 3.1 | 可求长曲线积分的存在性、实积分分解、参数公式、线性与方向、ML 估计及典型积分；连续性以弧长网格与共同加细处理 |
| 3.2 | Green 版本、折线逼近、Goursat 套三角形、局部原函数、连续边界版本、多连通域及围道变形；不预设导数连续 |
| 3.3 | 原函数、闭路积分为零与路径无关的等价关系、单连通域存在性、Newton–Leibniz、对数与绕数 |
| 3.4 | Cauchy 公式、Cauchy 型积分求导、任意阶导数与光滑性、多连通公式及例题；用核的精确余项建立首次求导 |
| 3.5 | Cauchy 不等式、Liouville、代数学基本定理、Morera 与局部形式；标明各结论所需的连续性及增长条件 |
| 3.6 | 外微分、Wirtinger 分解、复 Green 公式与 Cauchy–Pompeiu；逐项核对楔积方向、面积符号及小圆误差 |
| 3.7 | 支集与光滑截断、直接积分的准确收敛条件、局部化求导、正则性、任意域整体存在性及解的全体 |

教材对一般可求长 Jordan 边界的论证省略较多。本章先给出星形、分段光滑情形，再补一般边界的证明：明确弧长面积公式、Fubini、连续延拓和光滑化这些实分析前提，用边界管状邻域面积估计与连续模控制误差；多连通边界同样处理。不会把一般 Jordan 域默认成星形域。

§3.7 对任意域的整体存在性不使用未经证明的全域积分，也不循环引用第五章的 Mittag–Leffler 定理。先证明所需的有理逼近引理，再取相对无孔紧穷竭，对紧支集分块解减去全纯逼近项，使各阶导数级数在紧集上收敛。此部分明确标为进阶补证。

## 校勘与适用条件

正文按正确条件陈述，习题保留原文并把疑义另列。

- 例 3.4.7 的教材数值有误：相应围道积分为 96πi/4225，给出不使用留数理论的计算；高精度参数积分独立核对。
- 定理 3.7.3 原述任意 C¹ 数据的全域积分可能发散。有界域也不能仅凭内部 C¹ 保证可积。给出反例、加权 L¹ 充分条件及任意域存在性的另一构造。
- 积分求解只将内部紧支集密度补零，不假定任意函数补零后仍可微。
- 习题 3.1.7 注明曲线邻域全纯及像曲线重数；3.1.11 注明积分存在性不能仅由一点连续推出。
- 习题 3.2.3 注明指数与目标 2n 的对应；3.4.6 原下界 −1 不成立，正确的一般下界为 −2；3.4.7 补明非退化区间。
- 习题 3.5.3 注明积分围道应为三角形边界；3.6.3(2) 注明边界积分多写的积分号；3.7.3 注明极限给出的可去点延拓值。
