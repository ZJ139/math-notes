## 证明覆盖

| 节 | 复核的主要结论与方法 |
| --- | --- |
| 1.1 | 复数域公理、不可赋予有序域结构、共轭与模、三角不等式及取等条件 |
| 1.2 | 乘除法的极坐标形式、de Moivre、开方、单位根、垂直与平行判据、广义圆、交比、中点构造 |
| 1.3 | 球极投影的正逆公式、弦距、无穷远邻域、球面圆与平面广义圆 |
| 1.4 | 逐坐标收敛、唯一性和有界性、代数运算、Cauchy 准则、主辐角的局部连续性 |
| 1.5 | 内部、闭包、边界与导集；序列判据、Cantor、Heine–Borel、紧闭正距离、Bolzano–Weierstrass |
| 1.6 | 轨迹紧性、曲线长度、连通判据、开集折线连通、Jordan、圆盘单连通 |
| 1.7 | 极限与连续性的序列判据、运算法则、连续紧像、有界/极值/一致连续、紧集上连续单射的逆连续 |

Jordan 定理采用奇异同调证明，依赖同伦不变性、圆与圆盘的同调及 Mayer–Vietoris 正合列。正文明确说明其不是第一章初等分析范围内的自足证明，并链接 Hatcher《Algebraic Topology》第 2 章与 §2.B 命题 2B.1 的原始出处。先以闭弧二分消去补集的约化零维与一维同调，再对两条闭弧使用正合列得到恰好两个分支，并单独论证共同边界、有界/无界分支。未用 Jordan 定理循环证明闭弧补集连通。
