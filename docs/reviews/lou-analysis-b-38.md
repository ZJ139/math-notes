## 证明复核

- B261：修订命题说明积分函数类，并给 f(0) 的连续延拓。无穷远反例的区间长度为 2^(−k)/t_k，有限积分与发散复合积分分别逐项估算；零端点反例的高度取在 (0,1)，函数仍有界。两个构造均仅在零点累积跳点，因此适用于题目所在反常 Riemann 积分背景，也适用于非负 L¹。
- B262：分部积分符号为 1−2x∫t exp(−xt²) cos t；权的总变差积分恰为 1。边界项及余项绝对收敛分别说明。
- B263：使用 F(x)−x^(−1)∫F，两个部分都趋于同一 L。Cesàro 结论给出分段估计，不额外要求 f 绝对可积或点态衰减。
- B264：由中值定理向左推得下界，而非误推向右下界。f(0)=0 保证三角形左端 x−2f(x) 非负；无需假设导数连续。
- B265：离散分部求和中的 b_n=−1/2−(i/2)cot(θ_n/2) 符号直接验算。θ_n 单调且留在同一整周间隙，故 b_n 总变差可控；估计对任意整数子区间成立，足以控制不完整二进尾块。同号波段长度趋于无穷，取整误差可吸收；等号处波段下界为常数量级。
- B266：二阶估计分别数近整周项、估计其余连续段，参数选择为相位差到整周的距离 λ^(1/2)。高次差分的二阶导数用多重积分表达，所有平移自变量均在 [N,3N]，比较常数不依赖平移步长。r≥1 时取 H=floor(N^η)、η=d/[2(r+1)]，最终差分和的归一化量为 O(N^(−d/4))；r 次开方后 δ=d/[(r+1)2^(r+1)]。r=0 单独用更强的二阶估计。整数情形只由固定 H 的差分归纳推出 o(N)，未把 o(N) 错当作加权级数收敛的充分条件。绝对发散用 |sin|≥sin²，而非由有符号平均为零直接断言。
- B267：D 中的参数属于未定义情形，不与发散混写。慢相位的最近整数法给一般项不趋零；α=1 的子列来自对 π 的抽屉逼近。闭区间套每一层先避开前 j 个零分母参数，再在新的根旁取不含根的闭区间，故极限参数没有任何零分母，却有任意幂级别的小分母。几乎处处论证先证明均匀测度界，再截断倒正弦，使用非负积分换序；坏事件总测度可求和的结论也给出证明，没有假设事件独立。
