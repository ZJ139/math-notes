## 数学复核

B149：字面第一问用 x³ 直接证伪；字面第二问为已知 g 的恒等式。对显式校订后的第一问，2x²−x 满足三组数据，而残差恒为 −8(x−1/4)²−3/2，不能擅加非负性。校订第二问 Q=f'f''−18f 的介值性由 J'=2Q 得到，J=(f')²−36∫f。反设 Q 无零点后 J 单调，中值定理序列先确定 f'(1−)=3，避免假定端点导数连续。取紧邻右端的 f'>0 最大区间，再以 H=(f')³−27f² 的符号排除左端在内部；最后对 f^(1/3) 用中值定理矛盾。分数幂只在已证明 f>0 后使用。补充的 x² 三点数据例使用两次 Rolle，明示中间所需连续性。

B150：第一式直接用正最大值；第二式令 u=e^(−2x)f 后 u''≥0，以两个割线及导数单调性推出 u≤0；第三式令 v=e^(2x)f，得到 v''−3v≥0。没有误用原式中为正的零阶系数，也没有在非严格最大值处仅凭 u''≤0 与 u''≥0 强行产生矛盾。

B151、B152：统一令 u=(f−3)/(f+2)，非负性确保分母≥2及 −3/2≤u<1。导数计算给出 u'≥−5u 或 u'≤−5u；e^(5x)u 的单调性结合负无穷远极限 0 决定符号。两题均检查常值取等及半轴反例，验证全实轴假设的实际用途。

B153：g 不为零时构造 f−λ∫1/g，并用端点导数异号得到内部极值。跨越 g 的零点时，由 f 的差商选取 f' 有限且收敛的序列，使乘积趋于零；没有宣称乘积在零点连续。将任意非零目标值化为正值时，明确反向参数化仍保持导数乘连续函数的形式。零目标值、端点值及退化区间分别覆盖。

B154：取 ε=(2−α)/4；q₋=√(x²+ε²)−√(1+ε²) 严格凸、在 ±1 为零，其积分 A≤α(α−2)/4<0。选 m 使 α^(2m)>2m+1，q₊=x^(2m)−1 为凸偶函数，积分 B>0。q=Bq₋−Aq₊ 是正系数组合，严格凸且积分为零。F=∫₀ˣq 为光滑奇函数，四个条件及闭区间严格正三阶导数逐项成立；单独说明 m=1 时的常数项。用 α=1.001、1.01、1.1、1.5、1.9、1.999 的数值作交叉检查，均满足 A<0<B，包括接近两端时的参数；数值验证不代替正文的一般证明。
