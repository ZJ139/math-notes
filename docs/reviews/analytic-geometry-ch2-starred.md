## 数学复核

| 题号 | 方法与边界检查 |
| --- | --- |
| 2.2.13 | 先除以一次项系数的欧氏长度，再拆绝对值；分别处理相交、平行不重合、重合，以及 k 为 0、1、其他正值和负值。严格区分商 d1/d2=k 与距离关系 d1=k*d2 对公共点的约定；不将恒等式和不相容式误判为平面。 |
| 2.2.15 | 按八个卦限识别四面体，同时用八个半空间的交证明凸性；给出六顶点、八外侧三角面及内部和边界的严格区分。 |
| 2.2.16 | 仿射线段分量参数化，一次式值为端点值的凸组合；异号时唯一零点参数位于 (0,1)。不把仿射平面系数解释成欧氏法向量。 |
| 2.3.15 | 交点坐标给出列变换，将第四列化为零；给出两条不同平行直线作为逆命题的反例。 |
| 2.3.19 | 代入直线分量参数式得到两个齐次方向条件；系数独立时用二阶子式和消元证明唯一方向，相关时给出全部方向参数；单列严格平行所需的定点不在两原平面上的条件。 |
