## 定位与跳转规则

- 先以 F01（2006 Text 1）和 L34（2020 Text 1）试点，两者均打开相应直译 PDF 的第 1 页。
- 全部目标页码逐项读取 `reading-YYYY-translation.md` 的现有链接，并与 PDF 中的 Text 标题核对，不按 Text 编号推算页码。
- 74 条原句逐条与相应 Text 的英文段落匹配。仅归一化 PDF 空白、连字符、连字和标点字形，不改变网页原句。原句散列仍与原有基准一致。
- 默认打开 **Text 起始页**，不声称是句子的精确所在页。页面明确写出起始页码和直译资料的段号，并提供“文章目录与页码”备用入口；不支持 PDF 页码片段的阅读器可按显示页码查阅。
- 使用静态 Markdown 链接，无客户端推断或新依赖；保留五部分教学正文、原试卷链接、同篇互跳、前后篇导航和原网页地址。

## 可重复核查

`docs/reviews/sentence-v1-reading-links.json` 记录 29 份 PDF 的 SHA-256、116 个起始页及全部 74 条映射。执行：

```sh
python3 scripts/review-sentence-reading.py
```

默认只读，重新从 PDF 提取文字并与记录比较；只有人工复核材料变更后才使用 `--write`。`scripts/sentence-reading-links.test.ts` 将此核查纳入测试，同时验证年份 / Text 标签、索引链接、起始页、备用目录、段号提示与总目录一致。既有测试继续验证全部 87 份阅读 PDF 原始字节、74 条原句散列、五部分结构、试卷入口和句库导航。
