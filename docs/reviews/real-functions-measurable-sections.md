## 数学复核

| 主题 | 核验要点与处理 |
| --- | --- |
| 可测空间 | 保留教材 σ 环定义，不默认 X 可测；有限函数以水平集反推定义域可测。 |
| 广义实函数 | 定义中包含无穷阈值；说明只检验有限阈值时须另设定义域可测。 |
| 示性函数 | 区分可测域 E 上的函数与整个 X 上的函数，解释教材的 σ 代数条件。 |
| 可数极限 | 用水平集与 Cauchy 点集刻画；不可数上确界给出不可测反例。 |
| 简单逼近 | 先保留教材的 1/n 网格，再给出用于积分的二进非负递增构造。 |
| Borel 代表元 | 先在域外补零；替换可数个层后，在 Borel 收敛点集上取有限极限。 |
| 基本列与 Riesz | 直接估计可求和误差集的尾并，不误用无限测度空间的上连续性。 |
| 收敛关系 | 给出打字机、逃逸区间、无限尾区间及“只有一个收敛子列”的反例。 |
| 依测度运算 | 区分任意空间上的线性运算与有限测度下的连续代入；保留分母非零条件。 |
| Egorov | 同一个大集适用于所有精度；区分任意小测度删集与零测度删集。 |
| Lusin | 有界块上紧集逼近；一般空间用局部有限网格拼成闭集。没有误加全域有限测度假设。 |
| 可测代表元 | 非完全 Borel 测度空间上用非 Borel 零集子集说明几乎处处改值的限制。 |
| 应用 | 补全可测可加函数、中点凸函数的证明，尤其是局部上界到连续的二进估计。 |
| 复合 | 对照教材的 Cantor 同胚构造；区分连续外函数和连续内函数。 |
