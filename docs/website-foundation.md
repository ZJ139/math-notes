# 数学手记：内容边界与本机验收

本轮目标是让现有网站更容易持续维护。当前仓库已有首页、栏目、文章页、题号与年份目录、搜索及 PDF 入口；沿用这些页面，不重新初始化网站。

## 五类内容如何归档

| 内容类型 | 现有栏目与目录 | 必填内容 | 完成标准 |
| --- | --- | --- | --- |
| 数学文档 | 讲义 `content/notes/` | 背景、定义与前提、结论、证明、参考资料 | 结论条件完整，公式正常，能说明所用方法 |
| 习题分享 | 题库与作答 `content/problems/` | 题目与来源、思路、完整解答、方法总结 | 解答对应原题，步骤可复核，引用注明来源 |
| 学习感悟 | 文章 `content/essays/` | 遇到的问题、理解变化、未解决的问题、下一步 | 分清个人认识与已证明结论 |
| 题目收录 | 题库与作答 `content/problems/` | 题干、书名与版本、页码及题号、所需知识、解答状态 | 来源可追溯；有解答时可直接找到 |
| 书籍收录 | 书架 `content/books/` | 作者、版本、适读阶段、先修知识、进度、评价 | 能判断为什么读、从哪里读起 |

习题分享与题目收录使用同一个题库，但模板标签分别为“习题分享”和“题目收录”。一题可以先在同一篇中维护题干与解答；只有独立成篇有意义时才拆分，并互加实际网页链接。不重复上传同一 PDF。旧文章不强制改名或移动。

## 开始写作

1. 在网站页脚打开“管理资料”，点击“开始写作”。
2. 选择五种模板之一。可先展开“查看与复制模板”，复制到本地编辑；模板本身不生成公开文章、不参与搜索。
3. “新建…”打开 GitHub 编辑器并预填对应目录和内容；先将文件名改成独有且稳定的 `.md` 名称，再补全标题、简介、主题和正文。点击入口不会保存或发布。
4. 删除不用的空章节和说明，确认内容已可公开后提交。未完成正文留在本机，不以 `draft` 字段提交到公开仓库。
5. 有附件时，沿用 README 的上传与 `attachment` 关联流程；没有附件时不要填占位路径。普通来源链接放正文，或填写真实的 `source_url`。

不预填发布日期，避免模板生成时间被误当成文章更新时间。未填写日期时沿用仓库已有的 Git 提交日期规则。题库的 `problem_ids` 只在确实包含对应 A/S 题目时填写；期末考试和普通题目不伪造 A/S 编号。

## 首页与视觉基线

首页继续保留“数学、题库与作答、英语”三个入口与最近更新。五类内容是内容组织方式，不新增五个重复主导航。书架与参考链接保留既有位置。

沿用 AGENTS.md：纯白背景、Fandol 宋体正文与加粗标题、Latin Modern Roman 英文、Computer Modern / AMS 数学字体；屏幕正文 19–21px、约 1.55 倍行高、42.6em 最大行宽。黑色链接、蓝色交互与选中状态。PDF 不重新排版，附件字节不修改。

## 在自己的电脑上验收

环境与安装见 README 的“自动发布与本机检查”。需 Node.js 22.13 或更新版本、XeLaTeX 和 Poppler，构建需要访问 GitHub API。Windows 可在装好这些依赖的 WSL 环境中执行。

```sh
npm ci
npm run check
npm test
npm run build
npm run verify
npm run preview
```

打开 `http://127.0.0.1:4178/math-notes/`。预览使用已生成的 `dist/`；修改源码或内容后，重新构建再刷新。未成功构建时不要把旧预览当成本次成果。

| 检查 | 操作 | 通过标准 |
| --- | --- | --- |
| 首页与栏目 | 依次打开数学、题库与作答、英语、文章、书架 | 入口可达，既有内容保留 |
| 五种模板 | 管理资料 → 开始写作 → 分别打开编辑器 | 目录、中文模板和文件扩展名正确，未自动提交 |
| 正文与公式 | 打开现有数学讲义，检查行内公式、独立公式；题库检查矩阵、多行公式 | 不显示 LaTeX 源码或错误标记，中文和公式不缺字 |
| 手机阅读 | 用浏览器设备模式设置宽度 390px | 页面整体不横向溢出；长公式、表格仅在自身区域内滚动 |
| 桌面阅读 | 设置宽度 1440px | 正文行宽受限，标题与段落间距一致 |
| PDF | 从题库或讲义详情打开“阅读 PDF”及“下载附件” | 文件能打开，下载内容与原附件一致 |
| 返回与直达 | 从详情返回栏目，直接打开或刷新详情网址 | 目录和静态详情地址正常 |
| 无脚本与键盘 | 禁用 JavaScript 浏览模板；用 Tab 操作链接、展开模板 | 模板仍可读，焦点可见，入口能使用 |
