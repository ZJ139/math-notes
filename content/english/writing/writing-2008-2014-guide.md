## 读完题干后怎样构思

### 小作文：先填四项，再写三段

1. 确认“我是谁—写给谁—写什么体裁”。2010 年是研究生会通知，其余是信或邮件；2012 年正文代表学生会，结尾仍署 Li Ming。
2. 圈出必须完成的任务。比如 2008 年是道歉与解决方案，2009 年是观点与两到三条建议，2013 年是邀请外教担任评委。
3. 给每个任务填一项具体内容。建议配用途，邀请配时间地点和职责，招募配资格及报名方式。
4. 按“目的—主要信息—礼貌收束”写三段，最后查称呼、落款和字数。通知不套用信件称呼。

### 大作文：把图画变成一条论证链

1. 找画面中最重要的关系：2008 年是互补，2009 年是反差，2010 年是融合，2011 年是行为与后果，2012 年是同境不同态度，2013 年是多种选择，2014 年是时间与角色变化。
2. 用一句中文确定主张，再问“为什么”。不要从图画直接跳到空泛口号。
3. 用一个熟悉的例子或因果过程说明主张，再提出两项对应行动。画面没有出现的例子应放在分析段，不冒充描图事实。
4. 按“描图与点题—原因、例子与边界—评论与行动”写三段。可将约 40—50、80—90、40—50 词作为本专题的练习分配，具体随题调整。

## 优先背诵的六类句式

完整用例和逐句语法说明分布在各年范文中，共 42 组。背诵时同时记住表达用途和语法条件。

| 用途 | 可替换骨架 | 关键限制 |
| --- | --- | --- |
| 描述或推荐具体对象 | a person / a book that ... | 先确定先行词；关系词作主语时，从句谓语与先行词一致 |
| 礼貌提出请求 | I would appreciate it if you could ... | 保留 it；could 后用动词原形 |
| 表达最重要的一点 | What matters most is whether ... | whether 后保持陈述语序 |
| 强调原因、品质或方式 | It is ... that ... | 去掉强调框架后，余下部分能构成完整句子 |
| 强调必要条件或方式 | Only when / by ... can we ... | 主句部分倒装；when 从句仍正常语序，by 后接动名词 |
| 并列两项优点 | Not only does ... do ..., but it also does ... | 前半句 does 后用原形；后半句按主语变形 |

小作文可保留一至两处自然的复杂结构；本文部分篇目另提供简短句型便于迁移。大作文可选两至三处与意思匹配的结构，其他句子保持简洁。这是练习建议，不是评分规则。

## 怎样背成自己的表达

第一遍只读题意与构思，合上页面复述三段任务；第二遍读范文，找出每一句承担的任务；第三遍各选两句句式和四至五个搭配，换一个主题重新写。最后对照原题检查，而不是只检查是否背出了范文。

词汇优先背搭配，例如 express concern about、make a contribution、set realistic goals、offer practical help。遇到 crutches、disposable、sustainably 等题目相关词，可使用各页给出的常用替换，不必为一个生词打断整篇表达。
