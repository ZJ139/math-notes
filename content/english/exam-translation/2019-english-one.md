## 第 46 题

> There is a great deal of this kind of nonsense in the medical journals which, when taken up by broadcasters and the lay press, generates both health scares and short-lived dietary enthusiasms.

**参考译文**　医学期刊上有大量这类无稽之谈，一经广播电视媒体和面向普通公众的报刊传播，就会既引起人们对健康的恐慌，又掀起短暂的饮食热潮。

**语法与语序**　主句是存在句 *There is a great deal of this kind of nonsense in the medical journals*，其中 *there* 不表示“那里”。*a great deal of* 修饰不可数名词 *nonsense*，*in the medical journals* 说明这些说法出现的地方。*this kind of* 回指前面举出的那类看似精确、实则荒唐的医学研究说法，不泛指所有医学论文。

*which … generates …* 是定语从句，所指的是前面的这类无稽之谈。虽然最近的名词是复数 *journals*，但从句谓语 *generates* 是单数形式，且真正被传播并引起反应的是其中的说法，因此不能按“就近原则”把 *which* 接到期刊上。*when taken up by …* 插在 *which* 与 *generates* 之间，理解时可补成 *when it is taken up by …*；*taken up* 是被动意义的过去分词结构，逻辑主语仍是这类说法，*by* 后两项是传播者。

从句主干可缩为 *which generates both A and B*：A 是 *health scares*，B 是 *short-lived dietary enthusiasms*。*short-lived* 与 *dietary* 都修饰 *enthusiasms*，分别说明持续时间和热衷的内容。翻译时先说期刊中有什么，再接“这些说法一经传播，就会……”，不把整个长从句压成“……的无稽之谈”。参考译文省去了重复的“这些说法”，但没有换掉其施事关系。

**为什么这样译**　*lay* 与前面的专业医学期刊相对，表示非专业人士的；*the lay press* 是面向普通公众的报刊，不是“外行办的报社”。*broadcasters* 可以指广播电视机构或播报者，这里取传播渠道的意义，译作“广播电视媒体”。*take up* 在此是接过话题加以报道、传播，并非开始从事某项工作。*health scares* 是使公众担忧健康的恐慌，不等于已证实的健康损害；*dietary enthusiasms* 指对某些饮食做法一时热衷，译“饮食热潮”比“饮食热情”自然。*when* 与一般现在时结合，译“一经……就会……”；两项后果仍须用“既……又……”保留。

**生词与得分**　*short-lived* 可由 *short* 与 *lived* 理解为持续时间短；*dietary* 可联系 *diet*，词尾与位置共同提示它是形容词。*scares* 位于 *both A and B* 的 A 项，是复数名词；结合疾病、医学报道及后面的饮食反应，可判断它说的是“担心、恐慌”。*lay* 的词性由“修饰 *press*”确定，不能调用动词“放置”的义项。若一时不懂 *lay*，可暂写“这些说法经媒体和报刊传播后，既引起健康方面的担忧，也引发短暂的饮食热潮”，先保住内容、传播、两项后果，再补“普通公众”。这只是保全信息的暂译，遗漏限定仍应补齐。

**典型误译**　“医学期刊一旦被广播员拿起来，就会产生健康恐惧和短命的饮食爱好。”这里把 *which* 错接到期刊，把 *take up* 当作物理动作，把热潮持续时间短误写成生命短暂。“这些说法损害了公众健康”则把公众的恐慌换成实际的健康损害，超出了原句。检查时分别回答：传播的是什么、谁传播、产生哪两种反应。

## 第 47 题

> nowadays anyone applying for a research post has to have published twice the number of papers that would have been required for the same post only 10 years ago.

**参考译文**　如今，任何申请科研职位的人，都必须已经发表了相当于仅仅十年前申请同一职位所需数量两倍的论文。

**语法与语序**　主干是 *anyone … has to have published …*。*applying for a research post* 是现在分词短语，后置修饰 *anyone*，相当于 *who applies / is applying for a research post*；主动申请的人是 *anyone*。它没有另起谓语，也不是“申请之后”的时间状语。*has to* 表示要求，后面接完成式不定式 *have published*，说明在如今申请时，论文须已发表，不能译成入职之后再发表。

宾语中心是 *twice the number of papers …*。*that would have been required for the same post only 10 years ago* 是定语从句，给出用作比较基准的论文数量；*that* 在从句中作主语，*would have been required* 是带情态的完成被动结构。它设想“若在十年前申请同一职位，当时会被要求有多少论文”，不是说某位实际申请者已被录取，也没有断言当年的要求未被执行。*for the same post* 限定比较对象，*only 10 years ago* 是从句内的时间状语；主句的 *nowadays* 与之形成今昔对比。

**为什么这样译**　先译“如今，任何申请科研职位的人”，再接“都必须已经发表……”，把限定主语的分词短语前置，同时保留“必须”与“已经”。英语先说 *twice the number*，再交代比较基准，中文可先写“十年前同一职位所需数量”，最后落到“两倍”。*twice* 表示现在的要求是过去的两倍，即若过去要求 5 篇，现在便要求 10 篇；不能译为“比过去多两倍”，那通常会被理解为 15 篇。*only* 强调时间间隔之短，译“仅仅十年前”，不是“只需要十年”。

**生词与得分**　*post* 在 *apply for a research post* 中是可申请的“职位”，不能按“邮寄、帖子”取义；*papers* 与 *published* 搭配，是学术论文。*required* 可联系动词 *require*（要求），前面的 *been* 提醒这里是被动；*applying* 则来自 *apply*，与 *for* 连用表示申请。若只认识 *research* 而拿不准 *post*，可先写“申请科研工作的人”；若长定语暂未理清，先在草稿列出“如今／申请科研职位／必须已发表／同职位十年前所需数量的两倍”，再组织成完整中文，切勿只留下“现在要发表很多论文”。

**典型误译**　“现在任何正在申请研究岗位的人，都必须再发表比十年前多两倍的论文。”其中“再发表”丢掉了申请时已经具备的条件，“多两倍”改变了数量关系。另一个易错点是把 *only* 连到 *papers*，写成“只需发表两倍的论文”；原句强调的是“才过去十年”，不是降低要求。*same* 也不能略去后便把不同级别职位的要求混在一起比较。

## 第 48 题

> Attempts have been made to curb this tendency, for example, by trying to incorporate some measure of quality as well as quantity into the assessment of an applicant’s papers.

**参考译文**　人们已经作出一些努力来遏制这种趋势，例如，尝试在评估申请人的论文时，除考察数量外，也引入某种衡量质量的标准。

**语法与语序**　主干是 *Attempts have been made*，现在完成时的被动表达；*to curb this tendency* 是说明努力目标的不定式结构，可从 *make attempts to do …* 理解为“努力做……”。*this tendency* 承接上文只数论文数量、数量要求不断膨胀的倾向。*for example* 引出具体办法，不另起一项结论。

*by trying to incorporate … into …* 是方式状语。介词 *by* 后接动名词 *trying*，*trying* 后再接不定式 *to incorporate*；两者的行动者都是作出努力的人。核心搭配是 *incorporate A into B*：B 为 *the assessment of an applicant’s papers*，即对申请人论文的评估；A 要读成把质量的衡量同数量的考察一起纳入，而不是只按数量评估。*as well as quantity* 将数量与质量相联系，前文和下文的引用指标都表明这里是在原有数量考察之外增加质量维度。*of an applicant’s papers* 修饰 *assessment*，论文是被评估的对象；*an applicant’s* 是所有格。

全句没有带独立限定谓语的从句，难点在“被动作主干—不定式表目标—介词短语表方式—动名词后再接不定式”的层层嵌套。先找 *have been made*，就不会把 *trying* 当成主句谓语。

**为什么这样译**　汉语通常不说“尝试已被作出”，可恢复泛指的施事者“人们”，译为“已经作出一些努力”；原文没有交代具体个人或机构，因此不擅自补成“政府已经改革”。*attempts* 与 *trying* 都保留了尝试性质，不能说趋势已经得到遏制。*some measure of quality* 在此可理解为某种衡量质量的尺度或标准，结合下一句举出的引用指标，译“某种衡量质量的标准”清楚自然；它不是“采取一些提高质量的措施”，也没有声称已经找到完善的质量标准。

将 *into the assessment …* 提前成“在评估……时”，再用“除数量外，也……”表达 *as well as*，中文更容易读，也保留“质量与数量都要纳入”的关系。不能改成“用质量取代数量”，更不能从本句推出新办法已可靠地区分了论文优劣。

**生词与得分**　*curb* 在 *to* 后是动词，宾语是上文受到批评的趋势，因而可由语境判断为“遏制、限制”；在此不是名词“路缘”。*incorporate* 若不认识，先看 *A into B*，再看 A 是质量、数量，B 是评估，可暂取“把 A 纳入 B”，不靠拆字母硬猜。*assessment* 可由 *assess* 加名词后缀 *-ment* 认出；*applicant* 可与第 47 题的 *applying* 联系，指申请人，不能理解为申请文件。暂时不懂 *measure*，可先写“评估申请人的论文时，尝试把质量也考虑进去，同时考察数量”，随后补足“某种衡量标准”，并保留句首“已作出努力来遏制这种趋势”。

**典型误译**　“这种趋势已被遏制，例如采取一些质量措施来增加申请人的论文数量。”这把“作出尝试”升级为“成功”，把评价标准误成改造论文的措施，又把同时考察质量与数量写成单纯增加数量。判断译文时要分清三件事：努力的目标是遏制趋势，办法是改变评估内容，是否成功并未在本句中得到保证。

## 第 49 题

> This would be reasonable if it were not for the fact that scientists can easily arrange to cite themselves in their future publications, or get associates to do so for them in return for similar favours.

**参考译文**　要不是科学家能够很容易地安排在自己今后发表的论文中引用自己的研究成果，或让同行替自己这样做，并以同样的引用作为回报，这种办法本来是合理的。

**语法与语序**　主句是 *This would be reasonable*，*This* 指前文用论文被引用次数作为质量衡量依据的办法及其合理性判断，不是第 46 题中的无稽之谈。*if it were not for …* 引出与现实相反的假设条件，意思是“要不是有……”。这里的 *it* 是该条件表达中的形式成分，不宜强找一个前文名词对应；它与有实际指代的 *This* 作用不同。

*the fact that …* 中，*that* 引出说明事实内容的同位语从句，在从句内不担任主语或宾语。其主干是 *scientists can … arrange … or get …*：*can* 管辖由 *or* 连接的两种做法，*easily* 说明操纵很容易。*arrange to cite themselves …* 含不定式，行动者是科学家；*get associates to do so …* 是 *get + 宾语 + to do*，*associates* 是不定式 *to do* 的逻辑主语，表示让同行来做。

| 表达 | 指代或结构 | 翻译时必须保留的关系 |
| --- | --- | --- |
| *their future publications* | *their* 指科学家自己 | 在自己今后发表的论文中操作，不能译成未来研究会自然产生引用 |
| *cite themselves* | 研究语境下指引用自己的论文、研究成果 | 前一做法是自引，不是引用自己的名字 |
| *do so for them* | *so* 代替引用这些科学家的研究成果，*them* 指这些科学家 | 后一做法是请同行引用自己的成果，不是让同行引用同行自己的成果 |
| *in return for similar favours* | 说明后一做法中的互惠关系 | 同行替他们引用，他们也以类似的引用回报同行 |

*if* 从句提出的假设是“假如不存在这种可操纵性”，而 *the fact that …* 交代现实中确有这种可能。因此 *were* 与 *would* 不能被机械译成过去发生的事情；原句讨论的是这一办法现在是否合理。作者说科学家“能够”这样做，没有说所有科学家都已经这样做。

**为什么这样译**　英语先给出有条件的判断，后补条件，汉语把“要不是……”放在前面，再用“这种办法本来是合理的”收束，转折就清楚了。*cite themselves* 若逐字译为“引用自己”含义不够明白，可依据 *publications* 和前文的论文引用次数补明为“引用自己的研究成果”。这里补的是已经确定的对象，不是增加新的论点。

*associates* 是与科学家有联系的同行或同事，未限定为下属、助手。*favours* 泛指帮忙，但 *similar* 把回报同前面的引用行为联系起来，所以本句可说“以同样的引用作为回报”；不能无据写成金钱交易。也不要把两种操作升级为“伪造实验数据”：作者批评的是引用指标容易受到自引、互引影响。

**生词与得分**　*cite* 可联系上一句的 *citation index*；*citation* 的名词形式帮助认出本句动词是“引用”。*publications* 可与 *publish* 一起记，在这里指发表的论文。*associate* 平常也可作动词“联系”，但本句位于 *get* 与 *to do* 之间且用复数形式，是指人的名词；*favour* 的“帮忙”义由 *in return for*（作为对……的回报）及互引关系确定。若不懂 *associates*，暂写“让其他人替自己引用，并作类似回报”，至少保住两方和回报方向；再依据学术语境细化为同行。若 *cite* 一时拿不准，先读画线外对 *citation index* 的解释——论文在其他学术文献中被引述的次数——不要放弃整题。

**典型误译**　“如果科学家不引用自己，这种办法就合理。”这把“现实中容易操纵指标”缩减成“某些人选择不自引”，还漏了互引。“让同行引用他们自己”则容易被理解为同行自引，错换了被引用的对象。“因为科学家经常互相帮忙，所以这种办法合理”把虚拟条件的反面含义彻底译反。最后用两句话验意：现实中可以人为安排引用；如果没有这一问题，用引用次数判断质量才显得合理。

## 第 50 题

> If we are serious about ensuring that our science is both meaningful and reproducible, we must ensure that our institutions encourage that kind of science.

**参考译文**　如果我们确实认真致力于确保科学研究既有意义又可重复，就必须确保我们的科研机构鼓励这类研究。

**语法与语序**　句首先是 *If we are serious about …* 条件状语从句，主句是 *we must ensure …*。*be serious about* 后的 *about* 是介词，因此接动名词 *ensuring*；其后 *that our science is both meaningful and reproducible* 是宾语从句。该从句的主干为 *our science is A and B*，*both … and …* 连接两个并列表语，同时限定研究应具备的两项性质。

主句 *ensure* 后还有一个宾语从句：*that our institutions encourage that kind of science*。前一个 *that* 是引导词；*that kind of science* 中的 *that* 是限定 *kind* 的指示词，回指既有意义又可重复的科学研究，不能因为前面有两个 *that* 从句，就把这里也当成从句开头。*our* 属于作者将自己与读者纳入科研共同体的表达，不应擅自限定为“我国”。

本题的 *if + 现在时，must + 动词原形* 提出真实的条件要求，没有第 49 题那种与现实相反的虚拟语气；不能因为看到 *if* 就统一译作“要不是”。两个 *ensure* 各有对象：前一个是研究应有的性质，后一个是机构应当鼓励什么。

**为什么这样译**　*be serious about doing …* 说认真对待、确实打算做好某事，中文用“认真致力于……”连接后面的目标，比“关于确保……是严肃的”自然。*science* 在全文讨论论文质量和研究活动的语境中，译“科学研究”更明确；*institutions* 指与科研活动有关的机构，译“科研机构”与上文职业晋升、评估机制相衔接。可结合全文理解为这些机构的评价和激励应支持好研究，但不在参考译文中擅加具体政策。

*reproducible* 的中心是研究结果能够被重复检验、复现，不是论文可以复印或知识可以复制粘贴。参考译文用“可重复”，与“有意义”并列；也可译“可复现”，关键是指向科学研究。*encourage* 说鼓励、支持，不等于已保证所有研究达到目标；*must* 则是作者提出的必要要求，不能弱化为“可以考虑”。重复的 *ensure* 强调目标与实现条件相连，中文保留两次“确保”即可，不必为避免重复而改动语气。

**生词与得分**　*meaningful* 可由 *meaning + -ful* 理解为有意义的；*reproducible* 可联系 *reproduce* 与表示“能够……的”后缀 *-ible*，再用科研语境排除“能繁殖的”。构词法只给出方向，不能据此把词义写成“再次生产的”。*institution* 不能仅靠词尾猜出具体含义，要由前文晋升制度和论文评估确定此处所谈的机构。若暂不懂 *reproducible*，先保住“如果我们认真致力于确保研究有意义，并具备另一项性质，就必须确保科研机构鼓励这样的研究”的结构草稿，再回头判断第二项性质；不能把“另一项性质”直接交成答案，也不要编造“有创新性”来填空。

**典型误译**　“如果我们严肃地保证科学既有意思又能复制，我们的制度就会鼓励科学。”这把 *meaningful* 写成“有趣”，把科研可重复误成文本可复制，并把“我们必须确保机构鼓励”改成“机构自然就会鼓励”的结果。全文结尾提出行动要求，并未声称良好的机构激励已自动形成。

## 考场方法

1. **先给全文写出一条因果线。** 本篇从低质量论文的社会影响，追到重数量的评价，再讨论引用指标的漏洞，最后回到科研激励。第 48 题的 *this tendency*、第 49 题的 *This*、第 50 题的 *that kind of science* 各自承接不同内容，不能见到指示词便都译成同一个模糊的“这个”。上下文要读，画线外的内容不额外翻进答卷。
2. **先划主句谓语，再判断修饰层次。** 五题依次可缩为“有大量这类说法”“申请人必须已发表”“人们已经作出努力”“这种办法本来合理”“我们必须确保”。第 47 题的 *applying*、第 48 题的 *trying*、第 50 题的 *ensuring* 都不是主句的限定谓语。这个骨架仅用于草稿，最终必须补回时间、程度、条件和对象。
3. **代词用句法与语义双重核查。** 第 46 题的单数 *generates* 与“说法被传播”的语义共同排除复数 *journals*。第 49 题的 *do so* 要还原为“同行引用这些科学家的成果”，不要只把 *cite themselves* 原封不动抄到新主语后。找到指代后，中文可以用明确名词替换含糊代词。
4. **把数量、时间和语气单独验算。** 第 47 题用“过去 5 篇、现在 10 篇”检查两倍，用“申请时已发表”检查完成式；第 48 题区分“已作出努力”与“已取得成功”；第 49 题区分“现实中可以操纵”与“假如没有这种问题”；第 50 题保住 *must* 的必要性。不要把“可做”扩大为“都已做”。
5. **生词依次查词性、搭配、同族词和上下文。** *lay press* 靠专业期刊与公众媒体的对比取义，*research post* 靠 *apply for* 取义，*incorporate A into B* 靠搭配恢复动作方向，*cite* 可借 *citation index* 及紧接着的解释判断。*short-lived*、*meaningful* 等适合用构词法；无法可靠拆分的词不硬拆，也不把熟词的第一个义项直接塞进句子。
6. **不确定一个词时，保留其余信息的连接。** 先把“谁做什么、对什么做、通过什么方式、在什么条件下、程度和时间如何”写完整，再用语境支持的较宽表达暂代难词。例如第 48 题暂译“把质量也考虑进去”，仍应保留“同时考察数量”；第 49 题暂译“其他人”，仍须保留互引及回报方向。宽义暂译会损失精度，但好过删掉整项或凭空添加细节，最后应尽量细化。
7. **按汉语重排，再倒查有没有改变命题。** 后置定语可提前，长定语从句可另起短句，被动可恢复泛指主语，条件可前置；每次重排都要检查施事者、对象、否定和语气。第 46 题不能把恐慌改成实际伤害，第 48 题不能把纳入质量改成取代数量，第 50 题不能把行动要求改成自动发生的结果。

训练时先遮住译文，每题依次完成“圈出谓语—标明连接与指代—写出中文—回查限定”。对于英语一总分目标 60 分的复习，优先把五题的主干、并列项、时间和条件译完整，再提高中文的自然程度；不必为了追求华丽措辞冒险改变原意。复盘只记自己真正犯过的错，例如“把 *which* 接到最近名词”“把两倍译成多两倍”“把努力译成成功”，下一次先查这些位置。

## 建议记忆的单词与搭配

| --- | --- | --- |
| 必须掌握 | *medical / journal / nonsense* | 医学的／学术期刊／无稽之谈。*nonsense* 为不可数名词，可受 *a great deal of* 修饰。 |
| 必须掌握 | *diet / dietary / enthusiasm* | 饮食／饮食的／热衷、热情。*dietary enthusiasms* 在此是饮食热潮。 |
| 必须掌握 | *apply / applicant / require* | 申请／申请人／要求。把 *apply for a post* 与 *an applicant’s papers* 联在一起记。 |
| 必须掌握 | *publish / publication / cite / citation* | 发表／出版物、发表的论文／引用／引用。*citation index* 是引用指标，本文紧接着用被引次数解释。 |
| 必须掌握 | *tendency / curb / incorporate* | 趋势／遏制／纳入、包含。*incorporate A into B* 的方向是把 A 纳入 B。 |
| 必须掌握 | *assess / assessment / quality / quantity* | 评估／评估／质量／数量。注意 *quality* 与 *quantity* 拼写相近，意义不能互换。 |
| 必须掌握 | *reasonable / ensure / encourage* | 合理的／确保／鼓励。*would be reasonable* 与 *must ensure* 的语气不同。 |
| 必须掌握 | *meaningful / reproduce / reproducible* | 有意义的／重现、再现／可重复的、可复现的。放在科研语境中整体理解。 |
| 熟词僻义 | *lay / press / post / paper* | 非专业人士的／报刊、新闻界／职位／论文。每个义项都要用本篇搭配确认。 |
| 熟词活用 | *scare / measure / associate / favour* | 恐慌／衡量尺度、标准／同行、同事／帮忙。均为本篇中的名词用法；*associate* 在其他语境还可作动词“联系”。 |
| 熟词活用 | *science / institution* | 科学研究／机构。本文落在科研活动及其评价、激励上。 |
| 固定搭配 | *a great deal of / both A and B* | 大量……（后接不可数名词）／A 与 B 两者都。第 46、50 题均需保留并列两项。 |
| 固定搭配 | *take up / short-lived* | 接过话题进行报道、传播／短暂的。*take up* 的其他义项须另看搭配。 |
| 固定搭配 | *twice the number of …* | ……数量的两倍，不是比……多两倍。 |
| 固定搭配 | *make attempts to do / as well as* | 努力尝试做……／以及、除……之外也。尝试不等于成功，并列不等于替代。 |
| 固定搭配 | *if it were not for …* | 要不是……；设想现实中存在的因素并不存在。与主句 *would* 配合判断虚拟条件。 |
| 固定搭配 | *get somebody to do / in return for* | 让某人做……／作为对……的回报。写清行动者和回报双方。 |
| 固定搭配 | *be serious about doing / ensure that …* | 认真对待做某事／确保……。前者的 *about* 后用动名词，后者可接宾语从句。 |
| 上下文拓展 | *of small account / boil down … to … / metrics* | 无足轻重的／把……归结为、简化为……／衡量指标。这些表达帮助理解引用指标及量化评价的局限。 |

优先做到看见搭配便能确定关系，再记孤立释义：看到 *incorporate* 就标出 A 与 B，看到 *in return for* 就追问谁回报谁，看到 *both* 就检查另一项是否也已译出。词汇记忆要最终服务于完整、准确的句子理解。
