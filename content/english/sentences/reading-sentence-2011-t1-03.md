## 原句

> All I have to do is to go to my CD shelf, or boot up my computer and download still more recorded music from iTunes.

出处：2011年考研英语一阅读 Part A，Text 1，P3。[查看试卷原文](/files/english/exams/2011英一.pdf#page=2)。P 指文章自然段。

## 句子拆解

### 断句

> All / I have to do / is to go to my CD shelf, / or boot up my computer / and download still more recorded music / from iTunes.

“/”标出主要成分与嵌入结构的边界；结合下表判断哪些成分处于同一层级。断句不改变原句词序，不要求逐块机械翻译。

### 主干读法

All I have to do is to go to my CD shelf or boot up my computer and download music.

### 逐项分析

| 原句成分 | 语法作用 | 内部结构与理解 |
| --- | --- | --- |
| All I have to do | 主语及其定语从句 | All 在此为代词，表示我所需做的全部事情；I have to do 是省去关系代词 that 的限制性定语从句，that 在内部作 do 的宾语。 |
| I have to do | 定语从句内部 | I 为主语，have to 表必须、只需完成的要求；do 是动词原形，宾语空位对应 All。这里的 to 属于 have to，不是主句表语的 to。 |
| is to go to my CD shelf | 主句系表 | is 是主句系动词；to go ... 为不定式表语，说明具体只需做什么。go 后的 to 是方向介词，my CD shelf 为其宾语，CD 修饰 shelf。 |
| or boot up my computer | 并列选择 | or 连接两个可选途径；boot up 与 go 并列，共用表语不定式的 to。my computer 是 boot up 的宾语。 |
| and download still more recorded music | 第二途径内的并列动作 | and 将 boot up 与 download 连在一起：先启动电脑再下载。download 同样共用 to；recorded 是过去分词定语，music 为不可数宾语，still more 表还要更多的。 |
| from iTunes | 来源状语 | 依附 download，说明从 iTunes 下载；并非说明 CD 架子来自哪里。所有不定式的逻辑主语均为 I。 |

### 理解要点

全句有两种途径：去 CD 架，或开电脑并下载。or 的层级高于后一个 and；All ... is ... 把做法压缩成“我只需……”，服务于录音已很方便的论点。

## 句子直译

我所要做的，只是走到我的 CD 架前，或者启动电脑，从 iTunes 下载更多的录制音乐。

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立断句，标出主干、从句与非谓语的作用，再作直译。

### 迁移练习 1

> All we have to do is to open the file or visit the website and download a new copy.

**参考答案**

断句：All / we have to do / is to open the file / or visit the website and download a new copy.

**训练句直译**：我们所要做的，只是打开文件，或者访问网站并下载一份新副本。

**训练句拆解**：All 后省去宾语关系词 that；is 后 to open 与 visit ... and download ... 是两种途径。后两动词共用 to，new 修饰 copy。

### 迁移练习 2

> All she needs to do is check the figures and send the corrected report to her supervisor.

**参考答案**

断句：All / she needs to do / is check the figures and send the corrected report / to her supervisor.

**训练句直译**：她所需做的，只是核对数字，并把修正后的报告发给主管。

**训练句拆解**：she needs to do 为 All 的定语从句；前面已有 do，表语不定式可省 to，check 和 send 并列。corrected 作 report 的定语，to ... 表接收者。

### 考场价值

全句有两种途径：去 CD 架，或开电脑并下载。or 的层级高于后一个 and；All ... is ... 把做法压缩成“我只需……”，服务于录音已很方便的论点。

## 重要单词

“可能陌生”按约4000词词汇基础筛选，也包括熟词在本句中的特殊含义与搭配。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| all ... have to do is ... | 可能陌生（句式） | 所需要做的全部就是……，常译只需……。 |
| boot up | 可能陌生 | 启动电脑或系统。 |
| shelf | 核心 | 架子、搁板；CD shelf 为放光盘的架子。 |
| recorded music | 核心 | 已录制的音乐，与现场演奏相对。 |
| still more | 可能陌生（搭配） | 还要更多的，still 加强比较级。 |
| download | 核心 | 下载。 |
