## 原句

> This abrupt shift to an “intensive mothering narrative”, which suggests that mothers should manage childcare alone, was likely to have been harmful.

出处：2024年考研英语阅读 Part A，Text 2，P4。[查看原文上下文](/files/english/exams/2024英一.pdf#page=3)。P 指文章自然段；PDF 第 3 页为本篇所在页。

## 句子拆解

### 断句

> This abrupt shift / to an “intensive mothering narrative”, / [which suggests [that mothers should manage childcare alone]], / was likely / to have been harmful.

`/` 表示意群边界，`//` 表示同层并列分句边界，方括号表示嵌入结构；不改变原文用词。

### 主干读法

**This shift was likely to have been harmful.** which 从句插入说明 narrative 的主张。

### 逐项分析

| 成分 | 结构与作用 |
| --- | --- |
| This abrupt shift | 主句主语；This 回指前句所述家庭照顾方式的转变；abrupt 修饰 shift，表示突然。 |
| to an “intensive mothering narrative” | to 为介词，修饰 shift，表示转向的目标；an 限定 narrative，intensive mothering 作内容定语。 |
| which suggests … | 非限制性定语从句，which 指 narrative 并作主语；suggests 意为“传达、主张”，不是提建议时必定触发虚拟语气的用法。 |
| that mothers should manage childcare alone | suggests 的宾语从句；that 无句内成分；mothers 主语，should manage 谓语，childcare 宾语，alone 状语，强调母亲独自承担。 |
| was likely | 主句系表结构；过去时 was 与 shift 一致，likely 表“很可能”，保留不确定性。 |
| to have been harmful | likely 的不定式补足语；have been 为完成形式，表示伤害可能已经发生；harmful 是 be 的表语。 |

### 理解要点

which 说明的是育儿叙事的内容；主句评价的是这种转变。likely 和完成不定式同时出现，不应译成“已经证实有害”。

## 句子直译

这种突然转向“密集母职叙事”的变化很可能已经造成了伤害；这种叙事认为，母亲应当独自负责照料孩子。

## 原创拓展

以下两句为原创练习，不是历年试题原句。

### 迁移练习 1

> The sudden shift to a policy which assumes that workers can learn everything alone was likely to have been damaging.

**任务**：划分意群，指出主干及嵌入成分的作用，再作直译。

**参考答案**

**断句**：The sudden shift / to a policy [which assumes [that workers can learn everything alone]] / was likely / to have been damaging.

**训练句直译**：这种突然转向一项假定工人能够独自学会一切的政策的变化，很可能已经造成了损害。

**训练句拆解**：which 指 policy；that 为 assumes 的宾语从句；to have been 表伤害先于过去评价，likely 保留概率。

### 迁移练习 2

> This return to an old belief, which holds that children should remain silent in class, is likely to have limited discussion.

**任务**：划分意群，指出主干及嵌入成分的作用，再作直译。

**参考答案**

**断句**：This return / to an old belief, / [which holds [that children should remain silent in class]], / is likely / to have limited discussion.

**训练句直译**：这种重回旧观念的做法很可能已经限制了讨论；这种观念认为孩子上课应保持沉默。

**训练句拆解**：which 说明 belief；should remain silent 为系表结构；to have limited 为完成不定式，其宾语为 discussion；主句主语是 return。

### 考场价值

which 说明的是育儿叙事的内容；主句评价的是这种转变。likely 和完成不定式同时出现，不应译成“已经证实有害”。

## 重要单词

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| abrupt | 可能陌生 | 突然的，骤然的。 |
| shift | 核心 | 转变；shift to 表转向。 |
| narrative | 可能陌生 | 叙事、某种主导说法。 |
| intensive | 核心 | 密集的、投入程度很高的。 |
| childcare | 核心 | 儿童照料。 |
| harmful | 核心 | 有害的；likely to have been harmful 含概率判断。 |
