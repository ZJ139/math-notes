## 原句

> The most glaring flaw of the social cure as it’s presented here is that it doesn’t work very well for very long.

出处：2012年考研英语一阅读 Part A，Text 1，第 4 段。[查看试卷原文](/files/english/exams/2012英一.pdf#page=2)。

## 句子拆解

### 断句

“/”分隔意义组，“//”分隔同层并列分句；方括号标出嵌入结构，断句不改变词语归属。

> The most glaring flaw / of the social cure [as it’s presented here] / is [that it doesn’t work very well / for very long].

### 主干读法

The most glaring flaw is that it doesn’t work very well for very long. that 从句实际作表语，不是同位语。

### 逐项分析

| 原句成分 | 语法身份与内部结构 |
| --- | --- |
| The most glaring flaw | 主语中心为 flaw；the 限定，most glaring 是最高级定语，指最明显的缺陷。 |
| of the social cure | 介词短语后置修饰 flaw，说明是谁的缺陷。 |
| as it’s presented here | as 引导方式/限定说明，“按本书这里呈现的形式”；it 指 social cure，is presented 为一般现在时被动，here 指书中。 |
| is | 主句系动词，承接单数主语 flaw。 |
| that it doesn’t work very well for very long | 表语从句，解释缺陷的具体内容；that 不作内部成分，it 仍指社会疗法。 |
| doesn’t work very well | 否定的一般现在时谓语；work 是“奏效”，very well 修饰 work 的效果。 |
| for very long | 时长状语；very 修饰 long。否定与“很好、很久”结合，强调良好效果无法持久，并非断言从来完全无效。 |

### 理解要点

看到 flaw 后面的 that 要先找 is：这里已有系动词，因此是表语从句。for long 在否定句中常表示“不长久”。

## 句子直译

本书这里所呈现的社会疗法最明显的缺陷，是它不能在很长时间内持续发挥很好的作用。

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立断句，找出主干及指定结构，再做直译。

### 迁移练习 1

> The main weakness of the plan as it is described here is that it does not help small firms for very long.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：The main weakness of the plan [as it is described here] / is [that it does not help small firms / for very long].

**训练句直译**：按这里所描述的形式，这项计划的主要弱点在于，它无法长久地帮助小企业。

**训练句拆解**：as 从句说明计划呈现形式；that 从句作表语；for very long 是时长状语。

### 迁移练习 2

> The greatest advantage of the tool as we use it today is that it works without constant supervision.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：The greatest advantage of the tool [as we use it today] / is [that it works / without constant supervision].

**训练句直译**：按照我们今天的使用方式，这个工具最大的优点在于，它不需要持续监督就能运行。

**训练句拆解**：as 从句内部 we 主语、use 谓语、it 宾语；表语从句 that 后结构完整；without 短语表示运行条件。
