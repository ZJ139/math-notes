## 原句

> In today’s world, it has become normal that well-paid executives should not be accountable for what happens in the organisations that they run.

出处：2015年考研英语一阅读 Part A，Text 4，第 5 段。[查看试卷原文](/files/english/exams/2015英一.pdf#page=5)。

## 句子拆解

### 断句

“/”分隔意义组，“//”分隔同层并列分句；方括号标出嵌入结构，断句不改变词语归属。

> In today’s world, / it has become normal [that well-paid executives should not be accountable for [what happens in the organisations [that they run]]].

### 主干读法

It has become normal that executives should not be accountable ... . that 从句为真正主语；what 后再嵌一个修饰 organisations 的定语从句。

### 逐项分析

| 原句成分 | 语法身份与内部结构 |
| --- | --- |
| In today’s world | 全句时代/范围状语；today’s 所有格限定 world。 |
| it has become normal | it 形式主语，has become 现在完成时系动词，normal 表语，强调逐渐被视为常态。 |
| that well-paid executives | that 引导后置主语从句；executives 主语，well-paid 过去分词复合形容词作定语，指报酬丰厚。 |
| should not be accountable | should 为评价性表达，作者借 normal 批评竟然不必负责的现象，不是在建议“不应负责”；not 否定 accountable。 |
| for what happens ... | for 为 accountable 的搭配介词；what 从句作其宾语，what 在内部作 happens 的主语。 |
| in the organisations that they run | in 短语修饰 happens 的地点；organisations 为介词宾语；that they run 定语从句修饰它，that 为 run 的宾语，they 指 executives。 |

### 理解要点

what happens 的 what 是主语，that they run 的 that 是宾语，外层 that 则不作成分。三者承担的角色要分清。作者在揭露常态而非认可常态。

## 句子直译

在当今世界，薪酬丰厚的高管竟然无需对他们所管理的组织里发生的事情负责，这已经变得正常了。

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立断句，找出主干及指定结构，再做直译。

### 迁移练习 1

> It has become worrying that senior managers should know so little about what happens in the teams that they lead.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：It has become worrying [that senior managers should know so little / about [what happens in the teams [that they lead]]].

**训练句直译**：高级管理者竟然对自己领导的团队中发生的事知之甚少，这已成为令人担忧的现象。

**训练句拆解**：it 形式主语；should 表惊讶评价；what 作 happens 主语，that 作 lead 宾语。

### 迁移练习 2

> It seems unfair that volunteers should be blamed for what goes wrong in programmes that they cannot control.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：It seems unfair [that volunteers should be blamed / for [what goes wrong in programmes [that they cannot control]]].

**训练句直译**：志愿者竟然要为自己无法控制的项目中出现的问题受责备，这似乎不公平。

**训练句拆解**：评价性 should 加被动；what 作 goes 主语；that 在定语从句中作 control 的宾语。

### 考场价值

what happens 的 what 是主语，that they run 的 that 是宾语，外层 that 则不作成分。三者承担的角色要分清。作者在揭露常态而非认可常态。

## 重要单词

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| executive | 可能陌生 | 高管，管理人员 |
| well-paid | 核心 | 薪酬丰厚的 |
| accountable for | 可能陌生 | 对……负责，接受问责 |
| organisation | 核心 | 组织，机构 |
| run | 核心 | 管理，经营 |
| should | 核心 | 此处表示评价、惊讶，不是建议义务 |
