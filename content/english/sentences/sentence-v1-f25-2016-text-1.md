## 句子拆解

### 断句

> The French measures, / however, / rely too much on severe punishment / to change a culture / [that still regards beauty as skin-deep—and bone-showing].

“/”划分意群；方括号标出从句或嵌套成分。断句用于辨认结构，不表示每处都必须停顿。

### 主干读法

**主干读法**：The measures rely too much on severe punishment to change a culture.

### 逐项分析

| 原句成分 | 语法作用与内部结构 |
| --- | --- |
| The French measures, | 主语；The 限定前文法国措施，French 修饰 measures。 |
| however, | 转折插入副词，标示作者由政策目的转入对手段的批评。 |
| rely too much on severe punishment | 谓语 rely 与 on 搭配；too much 作程度状语，severe 修饰 punishment，整个名词短语作 on 的宾语。 |
| to change a culture | 目的不定式，说明依靠惩罚想达到的结果；change 的宾语为 a culture。 |
| [that still regards beauty as skin-deep—and bone-showing]. | that 指 culture，在定语从句中作主语；still 为状语；regards 为谓语，beauty 为宾语，as 后为对 beauty 的界定；破折号后的 bone-showing 与 skin-deep 递进并列。 |

### 理解要点

too much 批评依赖的程度；此处 to change 说明目的，不宜硬套“too…to＝太……而不能”并译成“无法改变文化”。regard A as B 是“把 A 视为 B”。

## 句子直译

然而，法国的这些措施过分依靠严厉的惩罚，来改变一种仍然把美视为只在外表、甚至要瘦得露骨的文化。

## 原创拓展

以下两句为原创练习，不是历年试题原句。建议先遮住参考答案完成断句与翻译。

### 迁移练习 1

> The school relies too much on exams to improve a system that still values scores above curiosity.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：The school / relies too much on exams / to improve a system [that still values scores above curiosity].

**训练句直译**：这所学校过分依靠考试，来改善一个仍然把分数看得比好奇心更重要的制度。

**训练句拆解**：to improve 为目的；that 在定语从句中作主语，values A above B 表把 A 看得高于 B。

### 迁移练习 2

> The policy, however, depends too heavily on fines to change habits that many drivers regard as harmless.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：The policy, however, / depends too heavily on fines / to change habits [that many drivers regard as harmless].

**训练句直译**：然而，这项政策过分依靠罚款，来改变许多司机认为无害的习惯。

**训练句拆解**：that 指 habits，在 regard…as 中作宾语；many drivers 是从句主语；too heavily 只评价依靠罚款的程度。

### 考场价值

理解批评对象是“手段过分严厉”，不是“作者反对改善健康审美”这一政策目标。
