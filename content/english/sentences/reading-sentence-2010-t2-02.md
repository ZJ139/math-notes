## 原句

> Later, more established companies raced to add such patents to their files, if only as a defensive move against rivals that might beat them to the punch.

出处：2010年考研英语一阅读 Part A，Text 2。[查看原文上下文](/files/english/exams/2010英一.pdf#page=3)（试卷 PDF 第 3 页）。

## 句子拆解

### 断句

“/”划分意群；先辨认限定谓语，再把从句与修饰语接回所属成分。断句完整保留原句词序。

> Later, / more established companies / raced to add such patents / to their files, / if only as a defensive move / against rivals / that might beat them to the punch.

### 主干读法

Companies raced to add patents to their files. 后半的 if only…说明即使只是防御，也会参与申请。

### 逐项分析

| 原句成分 | 作用及内部结构 |
| --- | --- |
| Later, | Later 是时间副词，与前文新兴网络公司的早期申请形成先后顺序。 |
| more established companies | 主语中心 companies；more established 是比较级形容词短语，指发展更成熟、地位更稳固的公司，不能把 established 当作这一句的谓语。 |
| raced to add such patents | raced 是主句限定谓语；to add 为不定式，说明争相行动的目的，such patents 为 add 的宾语。 |
| to their files, | add A to B 的目标成分；their 指这些公司，files 是其专利记录或档案。 |
| if only as a defensive move | if only 在此意为“哪怕只是、即便仅仅为了”，是缩略的让步说明，as a defensive move 说明行为目的或性质；不是 if only I were…一类愿望句。 |
| against rivals | against 引出防御的竞争对手，后置限定 defensive move；rivals 受后续定语从句修饰。 |
| that might beat them to the punch. | that 为关系代词、从句主语，指 rivals；might beat 为情态谓语，them 指那些成熟公司，beat somebody to the punch 为“抢先一步”。 |

### 理解要点

if only 不能一律译成“要是……就好了”。这里从实际行动补充最低限度的动机；might 保留竞争对手抢先的可能性。

## 句子直译

后来，发展更成熟的公司也争相把这类专利加入自己的档案，哪怕只是作为一种防御举措，以应对可能抢在它们前面的竞争对手。

## 原创拓展

以下两句为原创练习，不是历年试题原句。先独立作答，再核对参考答案。


### 迁移练习 1

> Several small publishers began to offer online courses, if only as a way to retain readers who might otherwise leave.

请独立断句，指出与原句对应的结构，再直译。

**参考答案**

断句：Several small publishers / began to offer online courses, / if only as a way to retain readers / who might otherwise leave.

**训练句直译**：几家小出版社开始提供网络课程，哪怕只是为了留住那些不这样做就可能离开的读者。

**训练句拆解**：if only 补充最低限度动机；to retain 修饰 way，who 为定语从句主语，otherwise 表相反条件。


### 迁移练习 2

> The laboratory repeated the experiment, if only to answer critics who had questioned the reliability of the first result.

请独立断句，指出与原句对应的结构，再直译。

**参考答案**

断句：The laboratory / repeated the experiment, / if only to answer critics / who had questioned the reliability of the first result.

**训练句直译**：实验室重复了这项实验，哪怕只是为了回应那些质疑首次结果可靠性的批评者。

**训练句拆解**：if only 后直接接目的不定式；who 修饰 critics，had questioned 为先于 repeated 的行为。

### 考场价值

if only 不能一律译成“要是……就好了”。这里从实际行动补充最低限度的动机；might 保留竞争对手抢先的可能性。

## 重要单词

以约4000词汇量为参照，“可能陌生”也包括熟词在本句中的特殊含义和固定表达。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| established | 核心 | 已站稳脚跟的，成熟的 |
| race to do | 核心 | 争相、争先去做 |
| if only | 可能陌生 | 此处：哪怕只是 |
| defensive | 核心 | 防御性的 |
| rival | 核心 | 竞争对手 |
| beat…to the punch | 可能陌生 | 先下手，抢在……之前 |
