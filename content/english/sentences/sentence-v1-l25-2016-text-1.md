## 句子拆解

### 断句

> It / tells the fashion industry / that it must take responsibility for the signal / [it sends women, especially teenage girls,] / about the social tape-measure / [they must use to determine their individual worth].

“/”划分意群；方括号标出从句或嵌套成分。断句用于辨认结构，不表示每处都必须停顿。

### 主干读法

**主干读法**：It tells the fashion industry that it must take responsibility for the signal.

### 逐项分析

| 原句成分 | 语法作用与内部结构 |
| --- | --- |
| It | 主语，指前文禁止过瘦模特的措施；不是形式主语。 |
| tells the fashion industry | 谓语 tells；the fashion industry 为告知对象。 |
| that it must take responsibility for the signal | that 引导告诉的内容，作宾语从句；it 指时尚业，must take 为情态谓语，responsibility 为宾语，for 引出负责的对象 the signal。 |
| [it sends women, especially teenage girls,] | 修饰 signal 的定语从句，省略作直接宾语的 that/which；it 为主语，sends 为谓语，women 为间接宾语；especially teenage girls 补充突出女性中的少女。 |
| about the social tape-measure | about 短语说明 signal 的内容；social 修饰 tape-measure，喻社会审美标尺。 |
| [they must use to determine their individual worth]. | 修饰 tape-measure 的定语从句，省略作 use 宾语的关系词；they 指 women，must use 为谓语；to determine 表使用标尺的目的，their individual worth 为 determine 的宾语。 |

### 理解要点

两个省略的关系词均在定语从句中作宾语，不能因没有 that 就把 it sends、they must use 当成新主句。最外层 It 与宾语从句内 it 指代不同。

## 句子直译

这告诉时尚业，它必须为自己传递给女性、尤其是少女的信号承担责任；这种信号涉及她们必须用来衡量个人价值的那把社会标尺。

## 原创拓展

以下两句为原创练习，不是历年试题原句。建议先遮住参考答案完成断句与翻译。

### 迁移练习 1

> The report tells teachers that they should explain the standards they use to assess students’ work.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：The report / tells teachers / that they should explain the standards [they use to assess students’ work].

**训练句直译**：这份报告告诉教师，他们应当解释自己用来评价学生作业的标准。

**训练句拆解**：主句 report tells teachers；that 引出宾语从句。they use 修饰 standards，省略 use 的宾语；to assess 是目的状语。

### 迁移练习 2

> The rule reminds companies that they are responsible for the messages they send customers about the products customers buy.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：The rule / reminds companies / that they are responsible for the messages [they send customers] / about the products [customers buy].

**训练句直译**：这项规定提醒公司，它们须对自己向顾客传递的、关于顾客所买产品的信息负责。

**训练句拆解**：that 后 companies are responsible 是内容；they send customers 修饰 messages，customers buy 修饰 products，两个省略关系词均作宾语。

### 考场价值

不要把 tape-measure 当作字面量尺；这里是社会审美标准的比喻。

## 重要单词

“可能陌生”按约 4000 词汇量估计；优先记住本句词义和搭配。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| responsibility | 核心 | take responsibility for 对……负责 |
| signal | 核心 | 传递给公众的信号或信息 |
| individual | 核心 | 个人的，修饰 worth |
| worth | 核心 | 价值，不是价格 |
| tape-measure | 可能陌生 | 卷尺，此处喻衡量标准 |
| teenage | 核心 | 十几岁的 |
