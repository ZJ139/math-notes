## 句子拆解

### 断句

> Just how people think / is still far too complex / to be understood, / let alone reproduced, / says David Eagleman, / a Stanford University neuroscientist.

“/”划分意群；方括号标出从句或嵌套成分。断句用于辨认结构，不表示每处都必须停顿。

### 主干读法

**主干读法**：Just how people think is far too complex to be understood, let alone reproduced. 句末 says David Eagleman 标出这一判断的来源。

### 逐项分析

| 原句成分 | 语法作用与内部结构 |
| --- | --- |
| Just how people think | 间接疑问主语从句；Just 修饰 how，表“究竟如何”；people 为从句主语，think 为谓语，how 为方式状语。 |
| is still far too complex | 主句 is 系动词，still 为时间状语，complex 为表语；far 加强 too，表示复杂程度远超过可理解的限度。 |
| to be understood, | too…to 中的不定式，采用被动，understood 的受事是人的思维方式；表示因过于复杂而尚无法理解。 |
| let alone reproduced, | 递进结构，省略重复的 to be；reproduced 为被动分词，“更不用说被复制”；复制比理解要求更高。 |
| says David Eagleman, | 后置报道分句；says 是报道动词，David Eagleman 是其主语，使用“动词 + 人名主语”的报道倒装；前面的判断为所报道内容。 |
| a Stanford University neuroscientist. | David Eagleman 的同位语，交代身份；neuroscientist 为中心名词，Stanford University 修饰其所属机构。 |

### 理解要点

整个 how 从句充当单数概念主语，所以用 is，不能把 people 与 is 错配。let alone 由较难走向更难，否定第一层后递进指出第二层更难做到。

## 句子直译

斯坦福大学神经科学家戴维·伊格尔曼说，人究竟如何思考，仍然复杂得远远无法被理解，更不用说被复制出来了。

## 原创拓展

以下两句为原创练习，不是历年试题原句。建议先遮住参考答案完成断句与翻译。

### 迁移练习 1

> Exactly how memory works is still too complex to be fully explained, let alone recreated.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：Exactly how memory works / is still too complex / to be fully explained, / let alone recreated.

**训练句直译**：记忆究竟如何运作仍然过于复杂，尚无法被充分解释，更不用说被重新创造。

**训练句拆解**：how 从句作主语；to be explained 被动；recreated 前省略 to be，递进难度。

### 迁移练习 2

> Why the system fails is not easy to determine, let alone predict.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：Why the system fails / is not easy to determine, / let alone predict.

**训练句直译**：系统为何失效并不容易确定，更不用说预测了。

**训练句拆解**：why 主语从句；easy 后不定式用主动形式表示主语是被确定的内容；predict 承前省略 to。

### 考场价值

“尚不能理解”与“更不能复制”是两级难度，不是说完全没有必要研究AI。
