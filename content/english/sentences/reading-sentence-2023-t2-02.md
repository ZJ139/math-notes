## 原句

> The state Legislature recently voted against a bill that would’ve made it illegal for towns to create legislation restricting short-term rentals.

出处：2023年考研英语阅读 Part A，Text 2。[查看原文上下文](/files/english/exams/2023英一.pdf#page=3)。定位：所附试卷 PDF 第 3 页；本句原文已核对。

## 句子拆解

### 断句

> The state Legislature recently voted / against a bill / that would’ve made it illegal / for towns to create legislation / restricting short-term rentals.

“/”划分意群；方括号标出从句或嵌套成分。断句用于辨认结构，不表示每处都必须停顿。

### 主干读法

**主干读法**：The Legislature voted against a bill that would have made local restrictions illegal.

### 逐项分析

| 原句成分 | 语法作用与内部结构 |
| --- | --- |
| The state Legislature recently voted | 主语 The state Legislature，recently 为时间副词，voted 为谓语，后接 against 表投票反对。 |
| against a bill | against 引出被否决对象 a bill，后面的 that 从句说明该法案原拟带来的效果。 |
| that would’ve made it illegal | 关系词 that 指 bill 并作从句主语；would’ve made = would have made，表示若通过会造成的结果；it 为形式宾语，illegal 为宾语补足语。 |
| for towns to create legislation | for towns 是不定式逻辑主语，to create legislation 为真正宾语，即原法案想认定为非法的行为。 |
| restricting short-term rentals. | restricting 为主动分词后置修饰 legislation；rentals 为 restrict 的宾语，short-term 修饰 rentals。 |

### 理解要点

两层方向不能读反：议会反对该法案；该法案原本要禁止地方限制短租。make it illegal 的 it 对应 towns to create legislation，而不是指短租行为本身。

## 句子直译

州议会最近投票反对一项法案；那项法案本来会使城镇制定限制短期出租的法规成为非法行为。

## 原创拓展

### 迁移练习 1

> The council rejected a proposal that would have made it difficult for schools to limit parking near entrances.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：The council / rejected a proposal [that would have made it difficult / for schools to limit parking near entrances].

**训练句直译**：议会否决了一项提案；该提案本会使学校难以限制入口附近的停车。

**训练句拆解**：rejected 与 would have made 的方向区分；it 形式宾语，for schools to limit 真正宾语。

### 迁移练习 2

> Lawmakers voted against a rule that would have made it illegal for residents to organize local markets.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：Lawmakers / voted against a rule [that would have made it illegal / for residents to organize local markets].

**训练句直译**：立法者投票反对一项本会使居民组织地方集市成为非法行为的规定。

**训练句拆解**：that 作 rule 定语从句主语；make it illegal 后由 to organize 说明被禁行为；voted against 并非通过。

### 考场价值

两层方向不能读反：议会反对该法案；该法案原本要禁止地方限制短租。make it illegal 的 it 对应 towns to create legislation，而不是指短租行为本身。
