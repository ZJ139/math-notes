## 原句

> We are fortunate that it is, because building new educational systems there and putting enough people through them to improve economic performance would require two or three generations.

出处：2009年考研英语一阅读 Part A，Text 3。[查看原文上下文](/files/english/exams/2009英一.pdf#page=4)。PDF 第 4 页为该篇文章所在页。

## 句子拆解

### 断句

“/”划分意群，“//”划分并列主句，方括号标出嵌入结构；断句符号用于阅读分析。

> We / are fortunate / [that it is], / because [building new educational systems there / and putting enough people through them / to improve economic performance] / would require two or three generations.

### 主干读法

We are fortunate that it is wrong, because building systems and educating people would require generations. 主干还原时补出的 wrong 来自上句，不属于原句的显式词语。

### 逐项分析

| 原文成分 | 语法作用与理解 |
| --- | --- |
| We are fortunate | 主句主系表；fortunate 意为幸运的。 |
| that it is | that 从句补充 fortunate 所针对的事实；it 指上句的 conventional view，即应把教育列为穷国经济增长最高优先事项之一的观点，is 后省略 wrong。不是说‘教育是幸运的’。 |
| because | 引导原因从句，解释为什么这一观点有误反而是好事。 |
| building new educational systems there | 动名词短语，构成原因从句主语的第一部分；building 的宾语 systems 带定语 new educational，there 指贫穷国家。 |
| and putting enough people through them | 第二个并列动名词短语；put people through education 表让人们完成教育，enough 修饰 people，them 指 systems。 |
| to improve economic performance | 不定式与 enough people 呼应，说明受教育人数要多到足以改善经济表现；同时交代这一教育路径的目标。improve 的宾语为 economic performance，economic 修饰 performance。不能漏掉 enough ... to ... 所表达的数量门槛。 |
| would require two or three generations | 原因从句谓宾部分；would 表设想这种教育先行路径所需的时间；two or three 修饰 generations，表示两三代人的跨度。 |

### 理解要点

最关键的是补回 is 后省略的 wrong。若读成‘这个观点正确，我们很幸运’，整段因果就会倒置：作者认为可以先通过在岗培训提升生产率，不必先等待数代教育建设完成。

## 句子直译

这个观点是错的，我们对此感到庆幸，因为在那里建立新的教育体系，并让足够多的人通过这些体系接受教育，以改善经济表现，将需要两三代人的时间。

## 原创拓展

以下两句为原创练习，不是历年试题原句。


### 迁移练习 1

> The claim that immediate replacement is necessary is mistaken. We are relieved that it is, because replacing all the equipment and training every worker to use it would take several years.

请先断句，指出主干及关键修饰关系，再直译。

**参考答案**：The claim [that immediate replacement is necessary] / is mistaken. // We / are relieved / [that it is], / because [replacing all the equipment / and training every worker to use it] / would take several years.

**训练句直译**：认为有必要立即更换设备的主张是错误的。我们对此感到宽慰，因为更换所有设备并培训每个工人使用这些设备，将需要好几年。

**训练句拆解**：首句说明该主张有误；第二句 it 指该主张，is 后省略 mistaken。because 从句的主语为两个并列动名词短语，to use it 补充 training，末个 it 指 equipment。


### 迁移练习 2

> The team was pleased that the proposal was unnecessary, because collecting new samples and checking them carefully would have delayed the project.

请先断句，指出主干及关键修饰关系，再直译。

**参考答案**：The team / was pleased / [that the proposal was unnecessary], / because [collecting new samples / and checking them carefully] / would have delayed the project.

**训练句直译**：团队很高兴该提案并非必要，因为收集新样本并仔细核查它们，本来会拖延项目。

**训练句拆解**：that 从句补充 pleased 的原因或内容；collecting 与 checking 并列作 because 从句主语；them 指 samples；would have delayed 表过去设想的后果。

### 考场价值

最关键的是补回 is 后省略的 wrong。若读成‘这个观点正确，我们很幸运’，整段因果就会倒置：作者认为可以先通过在岗培训提升生产率，不必先等待数代教育建设完成。

## 重要单词

“可能陌生”按约 4000 词汇量读者估计；熟词在本句中的特殊含义也单独列出。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| fortunate | 核心 | 幸运的，值得庆幸的 |
| educational system | 核心 | 教育体系 |
| put someone through | 可能陌生 | 使某人完成某种训练或教育 |
| performance | 核心 | 表现；这里指经济运行表现 |
| generation | 核心 | 一代人 |
| require | 核心 | 需要 |
