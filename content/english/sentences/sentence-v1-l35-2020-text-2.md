## 原句

> The success of Sci-Hub, which relies on researchers passing on copies they have themselves legally accessed, shows the legal ecosystem has lost legitimacy among its users and must be transformed so that it works for all participants.

## 句子拆解

### 断句

> The success of Sci-Hub, / which relies on researchers passing on copies / they have themselves legally accessed, / shows / the legal ecosystem has lost legitimacy among its users / and must be transformed / so that it works for all participants.

“/”分隔意群，“//”分隔同层并列分句或独立分句；方括号标出嵌入的从句或修饰部分。断句不改变原句成分之间的归属。

### 主干读法

The success shows (that) the legal ecosystem has lost legitimacy and must be transformed.

### 逐项分析

| 原句成分 | 结构、作用与内部关系 |
| --- | --- |
| The success of Sci-Hub, | The success 作主语；of Sci-Hub 是后置定语，说明谁的成功；逗号引出插入性说明。 |
| which relies on researchers passing on copies | which 指 Sci-Hub 并作关系从句主语；relies on 为谓语及介词补足结构；researchers 是 passing on 的逻辑主语，passing on copies 是介词 on 后的动名词结构，copies 为其宾语。 |
| they have themselves legally accessed, | copies 后省略关系代词 that/which；they 指 researchers，作主语；have accessed 为完成时，themselves 强调他们本人；legally 修饰 accessed；关系词所占的宾语位置留空。 |
| shows | shows 是主句谓语，切勿把插入的 relies 当成主句谓语；后接省略 that 的宾语从句。 |
| the legal ecosystem has lost legitimacy among its users | the legal ecosystem 为宾语从句主语；has lost 为谓语，legitimacy 为宾语；among its users 表明正当性不再被哪些人认可，its 指该体系。 |
| and must be transformed | and 连接同一主语 ecosystem 的两个谓语；must 表必要，be transformed 为被动，并非 users 要改造。 |
| so that it works for all participants. | so that 引导目的从句；it 指 ecosystem；works 为谓语，for all participants 说明服务对象，all 限定 participants。 |

### 理解要点

legal 是依法存在，legitimacy 是被人认作合理正当；二者不是同义重复。

## 句子直译

Sci-Hub的成功表明，现有合法出版体系已失去其用户对它正当性的认可，必须得到改造，以便为所有参与者发挥作用；Sci-Hub依靠研究人员传递他们自己合法获取的文献副本。

## 原创拓展

以下两句为原创练习，不是历年试题原句。

### 迁移练习 1

> The success of the library, which lends books residents have donated, shows that public services can improve so that everyone benefits.

**练习要求**：给句子断句，标明主干与修饰关系，再作直译。

**参考答案**

断句：The success of the library, / which lends books residents have donated, / shows that public services can improve / so that everyone benefits.

**训练句直译**：这家图书馆的成功表明，公共服务能够改善，从而让所有人受益；它出借居民捐赠的图书。

**训练句拆解**：which 指 library；residents have donated 修饰 books 且缺宾语；shows 后宾语从句；so that 为目的。

### 迁移练习 2

> The popularity of the scheme, which uses tools volunteers have repaired, shows the old system must change so that more people can join.

**练习要求**：给句子断句，标明主干与修饰关系，再作直译。

**参考答案**

断句：The popularity of the scheme, / which uses tools volunteers have repaired, / shows the old system must change / so that more people can join.

**训练句直译**：这个方案的流行表明，旧体系必须改变，以便更多人加入；该方案使用志愿者修好的工具。

**训练句拆解**：uses 的宾语 tools 带省略关系词的从句；shows 后省略 that；must change 主语为 system。

### 考场价值

抓“平台流行→现行出版制度正当性受质疑→需要改革”三步论证，勿将它读作作者主张没有著作权。

## 重要单词

“核心”侧重常用考研义与搭配；“可能陌生”按约 4000 词汇量筛选，重点记本句义。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| rely on | 核心 | 依赖 |
| pass on | 核心 | 传递、转交 |
| access | 核心 | 获取、查阅 |
| legitimacy | 可能陌生 | 正当性、获得认可的合理性 |
| ecosystem | 可能陌生 | 生态系统；此处指相互关联的出版体系 |
| transform | 核心 | 改造、转变 |
