## 原句

> Vaux says that Science’s idea to pass some papers to statisticians “has some merit, but a weakness is that it relies on the board of reviewing editors to identify ‘the papers that need scrutiny’ in the first place”.

出处：2015年考研英语一阅读 Part A，Text 3，第 6 段。[查看试卷原文](/files/english/exams/2015英一.pdf#page=4)。

## 句子拆解

### 断句

“/”分隔意义组，“//”分隔同层并列分句；方括号标出嵌入结构，断句不改变词语归属。

> Vaux says [that Science’s idea [to pass some papers to statisticians] / “has some merit, // but a weakness is [that it relies on the board of reviewing editors / to identify ‘the papers [that need scrutiny]’ / in the first place]]”.

### 主干读法

Vaux says that the idea has merit, but a weakness is that it relies on the board ... . 两个评价均在 Vaux 的观点范围。

### 逐项分析

| 原句成分 | 语法身份与内部结构 |
| --- | --- |
| Vaux says that | 主句主语、谓语和宾语连接词；下文全部为其评价。 |
| Science’s idea to pass some papers to statisticians | 宾语从句第一分句主语；idea 中心，to pass 修饰说明方案内容；papers 为 pass 宾语，to statisticians 表交给谁。 |
| has some merit | 第一评价的谓宾；some 限定有一定价值，不是全盘肯定。 |
| but a weakness is that ... | but 并列转折，weakness 为后半主语，is 系动词，that 引导表语从句。 |
| it relies on the board of reviewing editors | 表语从句主干；it 指方案，rely on 为依赖；board 中心，of reviewing editors 表由评审编辑组成。 |
| to identify ‘the papers that need scrutiny’ | 不定式说明依赖委员会去做的事，逻辑主语 board；identify 宾语 papers，that need scrutiny 为定语从句，that 作 need 主语。 |
| in the first place | 状语修饰识别所处环节，表示首先、在最初一步；不是物理空间中的第一处。 |

### 理解要点

三个 that 分别承担：says 的宾语连接、is 的表语连接、papers 的关系主语。方案弱点在筛选入口，不是统计学家完全没有作用。

## 句子直译

沃克斯说，《科学》把部分论文交给统计学家的想法“有一定价值，但一个弱点是，它首先仍依赖评审编辑委员会来识别‘需要仔细审查的论文’”。

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立断句，找出主干及指定结构，再做直译。

### 迁移练习 1

> The adviser says that the plan to invite outside experts has value, but a weakness is that it depends on managers to select the cases that deserve attention.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：The adviser says [that the plan [to invite outside experts] has value, // but a weakness is [that it depends on managers / to select the cases [that deserve attention]]].

**训练句直译**：顾问说，邀请外部专家的计划有价值，但一个弱点是，它依赖管理者挑选值得关注的案例。

**训练句拆解**：三个 that 依次为宾语、表语、定语；to invite 修饰 plan；to select 主语 managers。

### 迁移练习 2

> The new system has promise, but the problem is that it relies on users to report faults that they may not understand.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：The new system has promise, // but the problem is [that it relies on users / to report faults [that they may not understand]].

**训练句直译**：新系统有前景，但问题是，它依赖用户报告他们可能并不了解的故障。

**训练句拆解**：that 表语从句说明 problem；后一个 that 作 understand 的宾语；report 主体 users。

### 考场价值

三个 that 分别承担：says 的宾语连接、is 的表语连接、papers 的关系主语。方案弱点在筛选入口，不是统计学家完全没有作用。
