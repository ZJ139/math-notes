## 原句

## 句子拆解

### 断句

“/”分隔意义组，“//”分隔同层并列分句；方括号标出嵌入结构，断句不改变词语归属。

> Only if [the jobless arrive at the jobcentre with a CV, / register for online job search, / and start looking for work] / will they be eligible for benefit // — and then they should report weekly rather than fortnightly.

### 主干读法

还原：They will be eligible for benefit only if ... ; and then they should report ... . only if 条件前置使主句部分倒装。

### 逐项分析

| 原句成分 | 语法身份与内部结构 |
| --- | --- |
| Only if | only 限定 if 条件，表示“只有……才”；不是 if only“但愿”。该条件是领取救济资格的必要条件，非充分保证。 |
| the jobless | if 从句主语；the + 形容词表示一类人，指失业者。 |
| arrive at the jobcentre with a CV | 条件中第一并列谓语；at 表到达地点，with 表携带；CV 为简历。 |
| register for online job search | 第二并列谓语，共用 the jobless；for 表登记参加的事项，online 修饰 job search。 |
| and start looking for work | 第三并列谓语；start 后接动名词 looking，for work 是寻找对象；三个条件用 and 累加。 |
| will they be eligible for benefit | 主句部分倒装，will 前置，they 指失业者；be 系动词，eligible 表语，for benefit 为 eligible 的补足，表示有资格领取救济。 |
| and then they should report | 另一个完整分句，正常语序；then 表在取得资格之后，should 表制度要求，report 指到场报到。 |
| weekly rather than fortnightly | 并列对照的频率副词，修饰 report；每周一次，而非每两周一次。 |

### 理解要点

倒装发生在主句 will they，不发生在 if 从句；三项行为全部属于 only if 的条件范围。后半报到频率是另一个要求。

## 句子直译

只有失业者带着简历到就业中心、登记进行网上求职，并开始找工作，他们才有资格领取救济——而且此后他们应当每周报到一次，而不是每两周一次。

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立断句，找出主干及指定结构，再做直译。

### 迁移练习 1

> Only if applicants submit the form, provide a reference, and attend an interview will they be considered for the scholarship.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：Only if [applicants submit the form, / provide a reference, / and attend an interview] / will they be considered for the scholarship.

**训练句直译**：只有申请人提交表格、提供推荐材料并参加面试，他们才会被列入奖学金的考虑范围。

**训练句拆解**：三项条件累加；will they 部分倒装；be considered 为被动；完成条件不等于保证获奖。

### 迁移练习 2

> Only if the data are checked carefully can the findings be trusted, and then they should be reviewed independently.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：Only if [the data are checked carefully] / can the findings be trusted, // and then they should be reviewed independently.

**训练句直译**：只有数据经过仔细检查，研究结果才值得信任，而且此后还应接受独立审查。

**训练句拆解**：can 前置构成部分倒装；第二分句正常语序，they 指 findings；两个 be + 分词均为被动。

### 考场价值

注意这是“获得救济的必要条件”，不是“符合条件必然成功就业”。
