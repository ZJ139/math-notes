## 句子拆解

### 断句

“/”分隔意义组，“//”分隔同层并列分句；方括号标出嵌入结构，断句不改变词语归属。

> The court / would be recklessly modest / if [it followed California's advice].

### 主干读法

The court would be modest if it followed the advice. 这是对法院可能采纳意见的假设性评价。

### 逐项分析

| 原句成分 | 语法身份与内部结构 |
| --- | --- |
| The court | 主句主语，指最高法院；后面的 it 同指法院。 |
| would be | 主句虚拟/假设结果，would 加 be；不是叙述已经发生的过去事实。 |
| recklessly modest | 形容词 modest 作表语，recklessly 副词评价其程度/方式；modest 在司法语境指克制、不愿大幅裁定，recklessly 使评价转为过度克制、欠考虑。 |
| if it followed California's advice | 条件从句；it 主语，followed 为表示假设距离的过去式，并不必指实际过去；California’s advice 为宾语，advice 不可数。 |

### 理解要点

不能只见 modest 就判为称赞谦虚。recklessly 明确批评：过分克制会逃避为新技术提供规则的责任。

## 句子直译

如果法院听从加利福尼亚州的建议，那就会克制得近乎轻率。

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立断句，找出主干及指定结构，再做直译。

### 迁移练习 1

> The committee would be dangerously cautious if it postponed every difficult decision.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：The committee / would be dangerously cautious / if [it postponed every difficult decision].

**训练句直译**：如果委员会推迟每一个困难决定，那就会谨慎到危险的程度。

**训练句拆解**：would be 与 if 过去式构成假设；dangerously 改变 cautious 通常正面的评价。

### 迁移练习 2

> The editor would be irresponsibly polite if she refused to question any doubtful claim.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：The editor / would be irresponsibly polite / if [she refused to question any doubtful claim].

**训练句直译**：如果编辑对每项可疑说法都不提出质疑，她就会客气得不负责任。

**训练句拆解**：irresponsibly 修饰 polite；refused 后 to question 为不定式，any 在拒绝语境覆盖任何可疑说法；假设不表示已发生。

### 考场价值

不要看 modest 就判断全句褒义，也不能把假设读成已发生事实。
