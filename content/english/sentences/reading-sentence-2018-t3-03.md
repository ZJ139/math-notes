## 原句

> But this distinction misses the point that it is processing and aggregation, not the mere possession of bits, that gives the data value.

出处：2018年考研英语阅读 Part A，Text 3。[查看原文上下文](/files/english/exams/2018英一.pdf#page=4)。定位：所附试卷 PDF 第 4 页；本句原文已核对。

## 句子拆解

### 断句

> But this distinction misses the point / that it is processing and aggregation, / not the mere possession of bits, / that gives the data value.

“/”划分意群；方括号标出从句或嵌套成分。断句用于辨认结构，不表示每处都必须停顿。

### 主干读法

**主干读法**：This distinction misses the point that processing and aggregation give the data value.

### 逐项分析

| 原句成分 | 语法作用与内部结构 |
| --- | --- |
| But this distinction misses the point | But 转折；this distinction 指“控制数据”与“处理数据”的区分；misses 为谓语，the point 为宾语。 |
| that it is processing and aggregation, | that 引出 point 的具体内容；内容从句内为强调结构 it is…that；processing 与 aggregation 并列，是被强调的价值来源。 |
| not the mere possession of bits, | 插入排除项，not 否定另一个来源；mere 修饰 possession，of bits 说明所占有的是数据比特。 |
| that gives the data value. | 此 that 为强调结构的连接成分；gives 具有双宾语，the data 为间接宾语，value 为直接宾语。原文单数 gives 把处理与聚合视作一体的过程。 |

### 理解要点

外层 that 是 point 的内容从句，内层 that 属强调句。give A B 是“赋予 A 以 B”，不是“给出数据价值”这一整个宾语；作者强调价值生成过程，不只是数据持有。

## 句子直译

但这种区分忽略了关键所在：赋予数据价值的是处理与聚合，而不只是占有那些比特。

## 原创拓展

以下两句为原创练习，不是历年试题原句。建议先遮住参考答案完成断句与翻译。

### 迁移练习 1

> The argument misses the point that it is careful interpretation, not the size of a dataset, that gives evidence meaning.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：The argument / misses the point [that it is careful interpretation, not the size of a dataset, that gives evidence meaning].

**训练句直译**：这一论点忽视了关键所在：赋予证据意义的是细致解释，而非数据集的规模。

**训练句拆解**：point 后同位语从句嵌强调句；gives evidence meaning 是双宾语；not 对照被强调主语。

### 迁移练习 2

> The report emphasizes the fact that it is practice and reflection, not mere repetition, that makes training useful.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：The report / emphasizes the fact [that it is practice and reflection, not mere repetition, that makes training useful].

**训练句直译**：报告强调这一事实：使训练有用的是练习与反思，而不只是重复。

**训练句拆解**：外层 that 说明 fact；内层强调主语；makes training useful 中 useful 是宾补，区别于原句双宾语。

### 考场价值

外层 that 是 point 的内容从句，内层 that 属强调句。give A B 是“赋予 A 以 B”，不是“给出数据价值”这一整个宾语；作者强调价值生成过程，不只是数据持有。
