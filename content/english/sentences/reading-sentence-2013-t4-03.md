## 原句

> The Administration was in essence asserting that because it didn’t want to carry out Congress’s immigration wishes, no state should be allowed to do so either.

出处：2013年考研英语一阅读 Part A，Text 4，第 7 段。[查看试卷原文](/files/english/exams/2013英一.pdf#page=5)。

## 句子拆解

### 断句

“/”分隔意义组，“//”分隔同层并列分句；方括号标出嵌入结构，断句不改变词语归属。

> The Administration / was in essence asserting [that / because it didn’t want to carry out Congress’s immigration wishes, / no state should be allowed to do so either].

### 主干读法

The Administration was asserting that no state should be allowed to do so. because 从句在宾语从句内部解释禁止理由。

### 逐项分析

| 原句成分 | 语法身份与内部结构 |
| --- | --- |
| The Administration | 主句主语，行政当局。 |
| was in essence asserting | 过去进行时谓语 was asserting；in essence 插入状语表示实质上，assert 指宣称。 |
| that | 引出 asserting 的宾语从句；从句的主干要越过 because 部分后才出现。 |
| because it didn’t want to carry out Congress’s immigration wishes | 嵌入宾语从句的原因状语；it 指 Administration；didn’t want 谓语，to carry out 为 want 的补足；wishes 宾语，Congress’s 与 immigration 分别说明主体和领域。 |
| no state | 宾语从句的主语；no 为否定限定，表示任何州都不。 |
| should be allowed to do so | 情态被动谓语；allow somebody to do 变为 somebody be allowed to do；to do 的逻辑主语 state，so 替代执行国会移民意愿这一动作。 |
| either | 用于否定语境表示也；将联邦行政当局自己不愿执行与不准各州执行相连。 |

### 理解要点

不能在 that because 处误以为连接词重复。that 管整个内容，because 只管内容内部的原因；do so 的行为必须回到 carry out ... 才能确定。

## 句子直译

行政当局实质上是在宣称：因为它自己不愿执行国会在移民问题上的意愿，所以也不应允许任何州这样做。

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立断句，找出主干及指定结构，再做直译。

### 迁移练习 1

> The director was implying that because the central office did not wish to fund the project, no local branch should be allowed to do so either.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：The director was implying [that / because the central office did not wish to fund the project, / no local branch should be allowed to do so either].

**训练句直译**：主任是在暗示：因为总部不愿资助这个项目，所以也不应允许任何地方分部资助它。

**训练句拆解**：that 宾语从句包含 because 原因；do so 代 fund the project；either 配合 no。

### 迁移练习 2

> The report argues that because the software cannot explain its decisions, users should not be forced to trust it.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：The report argues [that / because the software cannot explain its decisions, / users should not be forced to trust it].

**训练句直译**：报告认为，因为软件无法解释自己的决定，所以不应强迫用户信任它。

**训练句拆解**：主句 argues 的宾语是整个 that 结构；because 内 its 指 software，末尾 it 同指软件；to trust 逻辑主语 users。

### 考场价值

不能在 that because 处误以为连接词重复。that 管整个内容，because 只管内容内部的原因；do so 的行为必须回到 carry out ... 才能确定。
