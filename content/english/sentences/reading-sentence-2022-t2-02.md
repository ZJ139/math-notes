## 原句

> This is not to say that there is no point in getting a degree, but rather stress that a degree is not for everyone, that the switch from classroom to lecture hall is not an inevitable one and that other options are available.

出处：2022年考研英语一阅读 Part A，Text 2。[查看原文上下文](/files/english/exams/2022英一.pdf#page=3)（试卷 PDF 第 3 页）。

## 句子拆解

### 断句

“/”划分意群；先找限定谓语，再辨认从句与修饰范围。断句完整保留原文词序。

> This is not to say / that there is no point in getting a degree, / but rather stress / that a degree is not for everyone, / that the switch from classroom to lecture hall is not an inevitable one / and that other options are available.

### 主干读法

This is not to say A, but rather stress B, C and D. not…but rather 对照两个表达意图；stress 后并列三个 that 从句。

### 逐项分析

| 原文成分 | 语法作用与内部结构 |
| --- | --- |
| This is not to say | This 指前文关于学位贬值、毕业生就业岗位的论述；is 后接不定式说明话语意图，not 否定的是‘要说下面这件事’。 |
| that there is no point in getting a degree | say 的宾语从句；there is 为存在结构，no point 表没有意义，in getting a degree 补充 point 的内容；getting 为动名词，degree 为宾语。 |
| but rather stress | 与 to say 并列，沿用前面的不定式标记 to；rather 表更确切地说，stress 是动词强调，不是名词压力。 |
| that a degree is not for everyone | stress 的第一个宾语从句；a degree 主语，is 系动词，for everyone 为介词表语；not for everyone 表并非适合每个人，不能扩大为对任何人都不适合。 |
| that the switch from classroom to lecture hall is not an inevitable one | 第二个并列宾语从句；switch 为主语，from…to…修饰 switch；is 为系动词，an inevitable one 为表语，one 替代 switch，not 否定必然性。 |
| and that other options are available | 第三个并列宾语从句；other options 为主语，are available 为系表，and 标明三个说明项的最后一项。 |

### 理解要点

有两个不同层次的否定：全文并不主张读学位毫无意义，而是反对把上大学视为适合所有人的必经道路。三个 that 从句共用 stress，不要把第二个 that 错接到 everyone。

## 句子直译

这并不是说获得学位毫无意义，而是要强调：学位并非适合每个人，从学校课堂转入大学讲堂并不是必然的一步，而且还存在其他选择。

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立作答，再核对参考答案。


### 迁移练习 1

> This is not to suggest that practice is useless, but rather emphasize that methods differ, that progress takes time and that rest also matters.

请先断句，指出主干及关键修饰关系，再作直译。

**参考答案**

**断句**：This is not to suggest / that practice is useless, / but rather emphasize / that methods differ, / that progress takes time / and that rest also matters.

**训练句直译**：这不是要说练习没有用，而是要强调：方法各不相同，进步需要时间，而且休息同样重要。

**训练句拆解**：not…but rather 对照 suggest 与 emphasize；第二个 to 共享；三个 that 从句并列作 emphasize 宾语。


### 迁移练习 2

> The report does not claim that remote work suits everyone; it argues that the choice depends on the task and that other arrangements should remain possible.

请先断句，指出主干及关键修饰关系，再作直译。

**参考答案**

**断句**：The report does not claim / that remote work suits everyone; / it argues / that the choice depends on the task / and that other arrangements should remain possible.

**训练句直译**：报告并未声称远程工作适合所有人；它认为，选择取决于任务，而且应保留其他安排的可能。

**训练句拆解**：前句 not 否定 claim，不能改读成远程工作不适合任何人；后句两个 that 从句共用 argues，remain possible 为系表。

### 考场价值

有两个不同层次的否定：全文并不主张读学位毫无意义，而是反对把上大学视为适合所有人的必经道路。三个 that 从句共用 stress，不要把第二个 that 错接到 everyone。

## 重要单词

“可能陌生”按约4000词汇量读者估计，也包括熟词在本句中的特殊含义和固定搭配。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| there is no point in | 核心 | 做……没有意义 |
| stress | 核心 | 动词：强调 |
| switch from ... to ... | 核心 | 从……转向…… |
| lecture hall | 核心 | 大学讲堂，阶梯教室 |
| inevitable | 可能陌生 | 不可避免的，必然的 |
| available | 核心 | 可获得的，可供选择的 |
| not for everyone | 核心 | 并非适合所有人 |
