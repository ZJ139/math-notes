## 原句

> But it’s also a lot more personal, Ortiz says, arguing that because art is so closely linked to a person, it could raise data protection and privacy problems.

出处：2024年考研英语阅读 Part A，Text 3，P7。[查看原文上下文](/files/english/exams/2024英一.pdf#page=4)。P 指文章自然段；PDF 第 4 页为本篇所在页。

## 句子拆解

### 断句

> But / it’s also a lot more personal, / Ortiz says, / arguing / [that because art is so closely linked to a person, / it could raise data protection and privacy problems].

`/` 表示意群边界，`//` 表示同层并列分句边界，方括号表示嵌入结构；不改变原文用词。

### 主干读法

**Ortiz says it is more personal, arguing that it could raise problems because art is linked to a person.** 报道语 Ortiz says 插在被转述的话后。

### 逐项分析

| 成分 | 结构与作用 |
| --- | --- |
| But | 转折连接，承接上一句关于收入损失的担忧。 |
| it’s also a lot more personal | 被转述内容的主系表；it 指未经授权使用作品这一问题；also 表还有一层，a lot 修饰比较级 more personal，意为“远不止经济层面，更涉及个人”。 |
| Ortiz says | 插入的报道主句，指出观点来自 Ortiz；并非原作者无来源断言。 |
| arguing that … | 现在分词短语补充 Ortiz 说话时的论证，逻辑主语 Ortiz；that 引导 arguing 的宾语从句。 |
| because art is so closely linked to a person | 嵌在 that 从句内部的原因从句；art 主语，is linked 被动谓语，so closely 状语，to a person 指与某个人相联系。 |
| it could raise | 原因从句之后回到 that 从句主干；it 指此类使用艺术作品的做法或问题，不是指刚出现的 person；could 表可能。 |
| data protection and privacy problems | raise 的宾语；problems 为中心词，data protection 与 privacy 并列修饰，指两类相关问题。 |

### 理解要点

遇到 arguing that because，不要将 that 与 because 合成一个连接词：that 接观点内容，because 在这个内容内部解释原因。

## 句子直译

但 Ortiz 说，这也更加涉及个人层面；她认为，由于艺术与个人联系如此紧密，这种做法可能引发数据保护和隐私问题。

## 原创拓展

以下两句为原创练习，不是历年试题原句。

### 迁移练习 1

> The issue is more personal, the writer says, arguing that because diaries reveal private experiences, their publication could harm the family.

**任务**：划分意群，指出主干及嵌入成分的作用，再作直译。

**参考答案**

**断句**：The issue is more personal, / the writer says, / arguing / [that because diaries reveal private experiences, / their publication could harm the family].

**训练句直译**：作家说，这个问题更涉及个人层面；他认为，因为日记揭示私人经历，出版它们可能伤害这个家庭。

**训练句拆解**：arguing 的逻辑主语是 writer；because 从句嵌在 that 宾语从句内；their 指 diaries，publication 是主干主语。

### 迁移练习 2

> The change is also educational, the teacher notes, explaining that because children learn through imitation, adults should examine their own habits.

**任务**：划分意群，指出主干及嵌入成分的作用，再作直译。

**参考答案**

**断句**：The change is also educational, / the teacher notes, / explaining / [that because children learn through imitation, / adults should examine their own habits].

**训练句直译**：老师指出，这种改变也与教育有关；她解释说，因为儿童通过模仿学习，成年人应审视自身习惯。

**训练句拆解**：the teacher notes 为报道主句；explaining 的逻辑主语 teacher；because 从句提供 should examine 的原因，their own 指 adults。

### 考场价值

遇到 arguing that because，不要将 that 与 because 合成一个连接词：that 接观点内容，because 在这个内容内部解释原因。

## 重要单词

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| personal | 核心 | 涉及个人的，不是“个性化”的唯一义项。 |
| argue | 核心 | 论证、主张，不一定是争吵。 |
| closely linked | 核心 | 紧密相关的。 |
| raise | 核心 | 引起、提出问题。 |
| data protection | 可能陌生 | 数据保护。 |
| privacy | 核心 | 隐私。 |
| a lot more | 核心 | ……得多；a lot 修饰比较级。 |
