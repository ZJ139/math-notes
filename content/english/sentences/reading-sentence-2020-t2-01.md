## 原句

> Scientists need journals in which to publish their research, so they will supply the articles without monetary reward.

出处：2020年考研英语一阅读 Part A，Text 2。[查看原文上下文](/files/english/exams/2020英一.pdf#page=3)（PDF 第 3 页，以本句英文定位）。

## 句子拆解

### 断句

> Scientists need journals / in which to publish their research, / so they will supply the articles / without monetary reward.

“/”分隔意群，“//”分隔同层并列分句或独立分句；方括号标出嵌入的从句或修饰部分。断句不改变原句成分之间的归属。

### 主干读法

Scientists need journals, so they will supply the articles.

### 逐项分析

| 原句成分 | 结构、作用与内部关系 |
| --- | --- |
| Scientists need journals | Scientists 是主语；need 为谓语；journals 为宾语，指学术期刊。 |
| in which to publish their research, | in which to publish… 后置修饰 journals，相当于 in which they can publish…；which 指 journals，作 in 的宾语；publish 的宾语为 their research，their 指科学家。 |
| so they will supply the articles | so 连接表结果的并列分句；they 指 Scientists；will supply 为谓语；the articles 为宾语。 |
| without monetary reward. | without 为介词，后接 monetary reward；monetary 修饰 reward；该介词短语说明提供论文时没有金钱报酬。 |

### 理解要点

in which 与 publish in a journal 对应；to publish 不是 need 的直接宾语，而是限定科学家所需的期刊。

## 句子直译

科学家需要能够发表研究成果的期刊，因此他们会不收取金钱报酬地提供论文。

## 原创拓展

以下两句为原创练习，不是历年试题原句。

### 迁移练习 1

> Students need a quiet room in which to prepare their talks, so the library keeps one open after class.

**练习要求**：给句子断句，标明主干与修饰关系，再作直译。

**参考答案**

断句：Students need a quiet room / in which to prepare their talks, / so the library keeps one open after class.

**训练句直译**：学生需要一间可以准备演讲的安静房间，因此图书馆在课后保持一间房间开放。

**训练句拆解**：in which 指 in a room；prepare 的逻辑主语 students；one 代替 room；open 为宾补。

### 迁移练习 2

> Researchers need reliable data on which to base their conclusions, so they check every record carefully.

**练习要求**：给句子断句，标明主干与修饰关系，再作直译。

**参考答案**

断句：Researchers need reliable data / on which to base their conclusions, / so they check every record carefully.

**训练句直译**：研究人员需要可据以形成结论的可靠数据，因此他们仔细核对每条记录。

**训练句拆解**：on 来自 base conclusions on data；which 指 data；so 连接结果分句。

### 考场价值

in which 与 publish in a journal 对应；to publish 不是 need 的直接宾语，而是限定科学家所需的期刊。

## 重要单词

“核心”侧重常用考研义与搭配；“可能陌生”按约 4000 词汇量筛选，重点记本句义。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| journal | 核心 | 学术期刊 |
| publish | 核心 | 发表、出版 |
| research | 核心 | 研究成果；不可数 |
| supply | 核心 | 提供 |
| monetary | 可能陌生 | 金钱的、货币的 |
| reward | 核心 | 报酬、回报 |
