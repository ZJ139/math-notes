## 原句

> The issue is not the need for more houses but, as always, where to put them.

## 句子拆解

### 断句

> The issue / is not the need for more houses / but, as always, / where to put them.

“/”划分意群；方括号标出从句或嵌套成分。断句用于辨认结构，不表示每处都必须停顿。

### 主干读法

**主干读法**：The issue is not the need but where to put the houses.

### 逐项分析

| 原句成分 | 语法作用与内部结构 |
| --- | --- |
| The issue | 主语，指住房争论的关键问题。 |
| is not the need for more houses | is 为系动词，not 否定第一个表语 the need；for more houses 修饰 need，more 限定数量。 |
| but, as always, | but 与 not 构成纠正式并列；as always 为插入状语，意为“一如既往”。 |
| where to put them. | where + to 不定式构成第二个表语，表示“应在哪里安置”；where 作 put 的地点补足成分，them 指 houses。 |

### 理解要点

not A but B 替换争论焦点；不是说住房不需要增加。where to put them 可展开为 where we should put them，疑问内容并不要求倒装。

## 句子直译

问题不在于是否需要更多住房，而是一如既往地，在于把住房建在哪里。

## 原创拓展

以下两句为原创练习，不是历年试题原句。建议先遮住参考答案完成断句与翻译。

### 迁移练习 1

> The difficulty is not whether to collect more data but how to interpret it.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：The difficulty / is not whether to collect more data / but how to interpret it.

**训练句直译**：困难不在于是否收集更多数据，而在于如何解释数据。

**训练句拆解**：两个疑问词不定式作并列表语；whether 表是否，how 表方式；it 指 data 所指的信息整体。

### 迁移练习 2

> Our concern is not the number of volunteers but, as before, where to send them.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：Our concern / is not the number of volunteers / but, as before, / where to send them.

**训练句直译**：我们关心的不是志愿者的人数，而是和以前一样，该把他们派到哪里。

**训练句拆解**：not…but 连接名词短语和疑问词不定式；as before 为插入语；them 指 volunteers。

### 考场价值

不能将作者的选址立场误判为反对增加住房供给。
