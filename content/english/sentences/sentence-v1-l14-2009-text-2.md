## 原句

> Critics also argue that commercial genetic testing is only as good as the reference collections to which a sample is compared.

## 句子拆解

### 断句

“/”划分意群，“//”划分并列主句，方括号标出嵌入结构；断句符号用于阅读分析。

> Critics / also argue / [that commercial genetic testing / is only as good as / the reference collections [to which a sample is compared]].

### 主干读法

Critics argue that testing is only as good as the collections. 检测质量受参照数据质量制约。

### 逐项分析

| 原文成分 | 语法作用与理解 |
| --- | --- |
| Critics also argue | 主句主谓；also 表补充另一项批评，argue 是提出论点而非吵架。 |
| that | 引导 argue 的宾语从句，不在从句内部充当成分。 |
| commercial genetic testing | 宾语从句主语；commercial 与 genetic 依次限定 testing。 |
| is only as good as | 系表比较结构；第一个 as 修饰 good，第二个 as 引比较对象，only 限定可达到的质量。 |
| the reference collections | 比较对象，reference 修饰 collections，指用来比对的参照样本／数据集合。 |
| to which | 介词前置的关系结构，引导定语从句修饰 collections；which 作 to 的宾语。 |
| a sample is compared | 定语从句主谓，is compared 为一般现在时被动；还原为 a sample is compared to the collections。 |

### 理解要点

only as good as 并非单纯赞扬‘一样好’，而是说上限取决于参照集合。to which 要与 compared 合读；which 不指 sample。

## 句子直译

批评者还认为，商业基因检测的可靠程度，最多也就等同于拿来与样本进行比较的参照数据集合的可靠程度。

## 原创拓展

以下两句为原创练习，不是历年试题原句。


### 迁移练习 1

> Researchers warn that a prediction is only as reliable as the evidence on which it is based.

请先断句，指出主干及关键修饰关系，再直译。

**参考答案**：Researchers / warn / [that a prediction / is only as reliable as / the evidence [on which it is based]].

**训练句直译**：研究人员提醒说，预测的可靠程度取决于它所依据的证据的可靠程度。

**训练句拆解**：that 宾语从句；on which 修饰 evidence，还原 it is based on the evidence；it 指 prediction。


### 迁移练习 2

> The map is only as accurate as the measurements with which it was produced.

请先断句，指出主干及关键修饰关系，再直译。

**参考答案**：The map / is only as accurate as / the measurements [with which it was produced].

**训练句直译**：这张地图的准确程度取决于制作它所用的测量数据的准确程度。

**训练句拆解**：as ... as 比较；with which 表工具或依据，修饰 measurements；it was produced 为被动，it 指 map。

### 考场价值

这不是说检测必然准确，而是说检测质量受参考资料的覆盖与准确性限制。

## 重要单词

“可能陌生”按约 4000 词汇量读者估计；熟词在本句中的特殊含义也单独列出。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| critic | 核心 | 批评者，持质疑观点的人 |
| argue | 核心 | 主张，论证 |
| genetic testing | 可能陌生 | 基因检测 |
| reference collection | 可能陌生 | 参照样本或数据集合 |
| sample | 核心 | 样本 |
| compare A to B | 核心 | 将A与B比较 |
| only as good as | 可能陌生 | 好坏取决于……的质量 |
