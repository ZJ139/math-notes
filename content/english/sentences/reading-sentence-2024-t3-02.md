## 原句

> Then he tried searching for his name to see if a piece he had worked on had been published.

出处：2024年考研英语阅读 Part A，Text 3，P4。[查看原文上下文](/files/english/exams/2024英一.pdf#page=4)。P 指文章自然段；PDF 第 4 页为本篇所在页。

## 句子拆解

### 断句

> Then / he tried searching for his name / to see / [if a piece [he had worked on] / had been published].

`/` 表示意群边界，`//` 表示同层并列分句边界，方括号表示嵌入结构；不改变原文用词。

### 主干读法

**He tried searching for his name to see if a piece had been published.** he had worked on 嵌在 if 从句的主语内部。

### 逐项分析

| 成分 | 结构与作用 |
| --- | --- |
| Then | 时间承接状语，表示随后。 |
| he tried searching for his name | 主谓及宾语；he 指 Rutkowski；tried doing 表尝试一种办法，searching 为动名词宾语；for his name 修饰 searching，his 同指艺术家。 |
| to see | 目的状语，逻辑主语是 he，意为“以弄清”。 |
| if | 引导 see 的宾语从句，意为“是否”，不是条件“如果”。 |
| a piece | if 从句主语中心，piece 在此是作品，a 表某件。 |
| he had worked on | 省略关系代词 that/which 的定语从句，修饰 piece；he 为主语，had worked 为过去完成时；piece 是 on 的逻辑宾语，不能省掉 on。 |
| had been published | if 从句谓语，过去完成时被动；been published 的承受者是 a piece，表示在搜索时点之前已被发表的可能情况。 |

### 理解要点

连续两个 had 分属不同层次：had worked 属于修饰 piece 的定语从句，had been published 才是 if 从句的谓语。

## 句子直译

随后，他试着搜索自己的名字，想看看一件他曾参与创作的作品是否已经发表。

## 原创拓展

以下两句为原创练习，不是历年试题原句。

### 迁移练习 1

> She searched the journal’s website to see if a report she had contributed to had been released.

**任务**：划分意群，指出主干及嵌入成分的作用，再作直译。

**参考答案**

**断句**：She searched the journal’s website / to see / [if a report [she had contributed to] / had been released].

**训练句直译**：她搜索了期刊网站，想看看一份她曾参与撰写的报告是否已发布。

**训练句拆解**：to see 表目的；if 表是否；she had contributed to 修饰 report，report 是 to 的逻辑宾语；had been released 为宾语从句谓语。

### 迁移练习 2

> He checked his email to find out whether a project he had applied for had been approved.

**任务**：划分意群，指出主干及嵌入成分的作用，再作直译。

**参考答案**

**断句**：He checked his email / to find out / [whether a project [he had applied for] / had been approved].

**训练句直译**：他查看电子邮件，想弄清一个他曾申请的项目是否已获批准。

**训练句拆解**：whether 引导 find out 的宾语从句；he had applied for 为定语从句；两处过去完成时分别对应申请、批准在查看之前。

### 考场价值

连续两个 had 分属不同层次：had worked 属于修饰 piece 的定语从句，had been published 才是 if 从句的谓语。
