## 原句

> Marketers have embraced the two-step flow because it suggests that if they can just find and influence the influentials, those select people will do most of the work for them.

出处：2010年考研英语一阅读 Part A，Text 3。[查看原文上下文](/files/english/exams/2010英一.pdf#page=4)（试卷 PDF 第 4 页）。

## 句子拆解

### 断句

“/”划分意群；先辨认限定谓语，再把从句与修饰语接回所属成分。断句完整保留原句词序。

> Marketers have embraced the two-step flow / because it suggests / that if they can just find / and influence the influentials, / those select people / will do most of the work for them.

### 主干读法

Marketers have embraced the theory because it suggests [if marketers find and influence certain people, those people will do the work]. if 从句整体在 that 宾语从句内部。

### 逐项分析

| 原句成分 | 作用及内部结构 |
| --- | --- |
| Marketers have embraced the two-step flow | Marketers 为主语，have embraced 为现在完成时谓语，the two-step flow 为宾语，指前文的“两级传播”理论；embrace 在此为接受某种观点。 |
| because it suggests | because 引导原因从句；it 指 the two-step flow，不是 marketers；suggests 为谓语，后接整个 that 宾语从句。 |
| that if they can just find | that 是宾语从句连接词；其内容先以 if 条件从句开头。if 内的 they 指 marketers，can 是情态动词，just 限定“只要能”，find 的宾语由后文 the influentials 补齐。 |
| and influence the influentials, | and 连接 find 与 influence 两个动词，二者共用 can 和宾语 the influentials；influence 是动词，influentials 是指有影响力者的名词。 |
| those select people | 条件所支配的结果分句主语；those 回指 influentials，select 为形容词“精选的、特定的”，不是过去式 selected。 |
| will do most of the work for them. | will do 为结果分句谓语；most of the work 为宾语，most 选取工作的大部分；for them 中 them 回指 marketers，即替营销人员完成推广。 |

### 理解要点

同一句中的 it、they、those select people、them 并不指同一对象。这里是理论给营销者提供吸引力的解释，不能脱离后文把理论当成作者已认可的事实。

## 句子直译

营销人员接受了两级传播理论，因为它表明：只要他们能找到并影响那些有影响力的人，那么这些特定的人就会替他们完成大部分工作。

## 原创拓展

以下两句为原创练习，不是历年试题原句。先独立作答，再核对参考答案。


### 迁移练习 1

> Teachers adopted the method because it suggested that if they could identify and support hesitant learners, those students would participate more actively.

请独立断句，指出与原句对应的结构，再直译。

**参考答案**

断句：Teachers adopted the method / because it suggested / that if they could identify and support hesitant learners, / those students would participate more actively.

**训练句直译**：教师们采用了这种方法，因为它表明：如果他们能识别并帮助犹豫的学习者，那么这些学生就会更积极地参与。

**训练句拆解**：it 指 method，they 指 teachers；if 嵌入 suggested 的 that 宾语从句，identify/support 并列，共用宾语 learners。


### 迁移练习 2

> The club welcomed the proposal because it promised that if members could share equipment, the savings would pay for better training.

请独立断句，指出与原句对应的结构，再直译。

**参考答案**

断句：The club welcomed the proposal / because it promised / that if members could share equipment, / the savings would pay for better training.

**训练句直译**：俱乐部欢迎这项提议，因为它有望做到：如果成员能够共用器材，节省的钱就能支付更好的训练费用。

**训练句拆解**：because 内 it 指 proposal；that 表提议预示的内容，if 是其中的条件；would 从过去视角表达预期结果。

### 考场价值

## 重要单词

以约4000词汇量为参照，“可能陌生”也包括熟词在本句中的特殊含义和固定表达。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| marketer | 核心 | 营销人员 |
| embrace | 可能陌生 | 此处：欣然接受观点 |
| two-step flow | 可能陌生 | 两级传播：媒介先到影响者，再到其他人 |
| influential | 可能陌生 | 此处名词：有影响力的人 |
| select | 可能陌生 | 形容词：精选的，特定的 |
