## 原句

> Sensible ideas have been around for a long time, but the state-level bodies that govern the profession have been too conservative to implement them.

## 句子拆解

### 断句

“/”分隔意义组，“//”分隔同层并列分句；方括号标出嵌入结构，断句不改变词语归属。

> Sensible ideas / have been around for a long time, // but the state-level bodies [that govern the profession] / have been too conservative / to implement them.

### 主干读法

Ideas have been around, but bodies have been too conservative to implement them. 问题在实施者，不在没有好想法。

### 逐项分析

| 原句成分 | 语法身份与内部结构 |
| --- | --- |
| Sensible ideas | 第一分句主语；sensible 意为合理、切实可行，不能与 sensitive 混淆。 |
| have been around for a long time | 现在完成时；be around 指存在，for a long time 为持续时间状语。 |
| but | 连接两个完整分句，转向未实施的原因。 |
| the state-level bodies | 第二分句主语中心 bodies，此处指机构而非身体；state-level 为州级的。 |
| that govern the profession | 限制性定语从句修饰 bodies；that 作主语，govern 谓语，profession 宾语，指律师行业。 |
| have been too conservative | 现在完成时系表；too 修饰 conservative，表示保守程度过高。 |
| to implement them | 与 too 呼应的不定式，表示高程度造成的否定结果；其逻辑主语为 bodies，them 指 sensible ideas。 |

### 理解要点

现在完成时突出合理想法早已存在与保守态度延续。too ... to ... 在这里意味着未能实施，不是“很保守以便实施”。

## 句子直译

合理的想法早已存在了很长时间，但管理这个行业的州级机构一直过于保守，无法把这些想法付诸实施。

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立断句，找出主干及指定结构，再做直译。

### 迁移练习 1

> Useful suggestions have existed for years, but the committees that control the budget have been too cautious to adopt them.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：Useful suggestions / have existed for years, // but the committees [that control the budget] / have been too cautious / to adopt them.

**训练句直译**：有用的建议已存在多年，但控制预算的委员会一直过于谨慎，未能采纳它们。

**训练句拆解**：that 指 committees；them 指 suggestions；too cautious to adopt 表谨慎过度导致未采纳。

### 迁移练习 2

> The evidence is clear, but the officials who manage the project are too defensive to admit the mistake.

任务：标出从句或非谓语边界，说明修饰关系，并直译全句。

**参考答案**

断句：The evidence is clear, // but the officials [who manage the project] / are too defensive / to admit the mistake.

**训练句直译**：证据很清楚，但管理项目的官员防卫心过强，不肯承认错误。

**训练句拆解**：who 作定语从句主语；不定式逻辑主语 officials；too ... to 的否定来自程度结构。

### 考场价值

不要将“缺少合理想法”误作改革停滞原因；问题在于执行者不愿实施。
