## 原句

> It never rains but it pours.

## 句子拆解

### 断句

> It / never rains / but / it pours.

“/”标出主要成分边界，“//”分隔同层并列分句，“[ ]”标出从句或嵌入修饰；原句中的括号与破折号保留。断句用于辨认结构，不要求逐块机械翻译。

### 主干读法

Whenever it rains, it pours.（释义改写，不替代原句）

### 逐项分析

| 成分 | 语法作用 | 结构与理解 |
| --- | --- | --- |
| It | 天气结构的形式主语 | 第一个 it 与 rains 搭配，谈天气，无具体指代对象。不能向前寻找某家公司作为先行词。 |
| never rains | 前半句谓语 | rains 为一般现在时第三人称单数，never 表否定；但须结合整个 never ... but ... 谚语理解，不是单独断言“这里从不下雨”。 |
| but | 固定关联结构的连接词 | 本谚语中的 never ... but ... 表示一发生前项，后项总相随，可释为 whenever it rains, it pours；不能照普通 but 转折译作“从不下雨，但是倾盆下雨”。 |
| it pours | 后半句主谓 | 第二个 it 仍是天气形式主语；pours 为一般现在时，pour 表大雨倾盆而下，不带宾语。 |
| 整句的比喻作用 | 篇章引入 | 字面为“不下则已，一下就倾盆”，本文指麻烦接踵而来：会计和公司治理问题刚理顺，又出现数据安全问题。它不是预测当地天气。 |

### 理解要点

先识别固定谚语，再回到随后举出的公司困境确定语境义。“祸不单行”符合本段，不能把它泛化为作者在讨论降雨量。

## 句子直译

不下则已，一下便是倾盆大雨。语境中意为：祸不单行。天气形式主语 it 不必译成“它”。

## 原创拓展

以下两句为原创练习，不是历年试题原句。先独立断句、辨认主干和从句，再核对参考答案。

### 迁移练习 1

> It never rains but it pours: just as the printer was repaired, the office network failed.

**练习要求**：先译谚语，再说明冒号后提供什么证据。

**参考答案**

断句：It never rains but it pours: // [just as the printer was repaired], / the office network / failed.

**训练句直译**：真是祸不单行：打印机刚修好，办公室网络又出了故障。

**训练句拆解**：冒号后以接连故障解释谚语。just as 为时间从句引导结构，the printer was repaired 为一般过去时被动；主句 network failed 为主动。

### 迁移练习 2

> It never rains but it pours; after losing a key, the student discovered that her phone had stopped working.

**练习要求**：说明 after 短语的逻辑主语及 that 从句的时态。

**参考答案**

断句：It never rains but it pours; // after losing a key, / the student / discovered / [that her phone had stopped working].

**训练句直译**：真是祸不单行：丢了钥匙后，这名学生发现她的手机也已经不能用了。

**训练句拆解**：losing 的逻辑主语为 the student，a key 为其宾语；that 从句作 discovered 的宾语，phone 为内部主语，had stopped 为过去完成时，working 接在 stop 后表示停止运行。

### 考场价值

以篇章为单位理解：旧治理问题尚未摆平，新的数据安全危机又到来。

## 重要单词

“可能陌生”按约4000词词汇基础筛选，包含熟词在本句中的特殊义与搭配；语境扩展另行标明。

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| it | 核心（语法用法） | 天气句中的形式主语，无具体先行词。 |
| rain | 核心 | 下雨；本句作动词。 |
| pour | 可能陌生（熟词义） | 大雨倾盆而下；此处不表示向容器倒水。 |
| never ... but ... | 可能陌生（固定表达） | 一旦……总是……；须结合固定谚语理解。 |
| It never rains but it pours. | 可能陌生（谚语） | 不下则已，一下倾盆；本段喻祸不单行。 |
