## 原句

> After writing two books about the history of inventions, one thing I’ve learnt is that while it is the enchantingly sophisticated technologies that get all the hype, it’s the cheap technologies that change the world.

出处：2024年考研英语阅读 Part A，Text 1，P6。[查看原文上下文](/files/english/exams/2024英一.pdf#page=2)。P 指文章自然段；PDF 第 2 页为本篇所在页。

## 句子拆解

### 断句

> After writing two books about the history of inventions, / one thing [I’ve learnt] / is / [that while it is the enchantingly sophisticated technologies that get all the hype, / it’s the cheap technologies that change the world].

`/` 表示意群边界，`//` 表示同层并列分句边界，方括号表示嵌入结构；不改变原文用词。

### 主干读法

**One thing I’ve learnt is that cheap technologies change the world.** 表语 that 从句内，while 对照两个强调结构。

### 逐项分析

| 成分 | 结构与作用 |
| --- | --- |
| After writing two books about the history of inventions | after 接动名词短语作时间状语；writing 的宾语 two books，about … 修饰 books，of inventions 修饰 history。语义上的写作者是 I；原句主语中心为 thing，属于作者导向的松散衔接，仿写宜用 After writing …, I have learnt … 避免悬垂。 |
| one thing I’ve learnt | 主句主语；one 限定 thing；I’ve learnt 是省略关系代词 that/which 的定语从句，thing 为 learnt 的宾语，I 为主语，have learnt 为现在完成时。 |
| is that … | is 为系动词；that 引导表语从句，在从句内部不作成分。 |
| while | 在表语从句内引导让步兼对照成分，意为“虽然”。 |
| it is … that get all the hype | 强调句框架；强调主语 technologies；复数谓语 get 由 technologies 决定，不由形式 it 决定。 |
| the enchantingly sophisticated technologies | 被强调的主语；sophisticated 修饰 technologies，enchantingly 修饰 sophisticated，表示复杂精巧得令人着迷。 |
| all the hype | get 的宾语；all 限定 hype，指大量宣传炒作。 |
| it’s the cheap technologies that change the world | 第二个强调句；被强调主语为 the cheap technologies；change 为谓语，the world 为宾语。两句 it 均不是指代具体技术的代词。 |

### 理解要点

删去两个 it is … that，分别得到“复杂技术得到宣传”“便宜技术改变世界”。句首分词的逻辑作者和语法主语并不完全匹配，理解原文时还原 I，仿写时主动消除悬垂。

## 句子直译

在写过两本关于发明史的书之后，我学到的一点是：虽然获得所有热烈宣传的是那些复杂精巧得令人着迷的技术，但改变世界的却是那些廉价技术。

## 原创拓展

以下两句为原创练习，不是历年试题原句。

### 迁移练习 1

> After interviewing several teachers, I have learnt that while it is the newest tools that attract attention, it is patient guidance that changes students’ habits.

**任务**：划分意群，指出主干及嵌入成分的作用，再作直译。

**参考答案**

**断句**：After interviewing several teachers, / I have learnt / [that while it is the newest tools that attract attention, / it is patient guidance that changes students’ habits].

**训练句直译**：采访几位教师之后，我了解到：虽然吸引注意的是最新的工具，但改变学生习惯的是耐心的指导。

**训练句拆解**：句首 interviewing 的逻辑主语 I 与主句一致；that 引导宾语从句；while 中的强调句突出 tools，主句强调 guidance，分别搭配 attract/changes。

### 迁移练习 2

> One lesson we have learnt is that while it is expensive equipment that makes headlines, it is careful training that prevents accidents.

**任务**：划分意群，指出主干及嵌入成分的作用，再作直译。

**参考答案**

**断句**：One lesson [we have learnt] / is / [that while it is expensive equipment that makes headlines, / it is careful training that prevents accidents].

**训练句直译**：我们学到的一个教训是：虽然成为新闻焦点的是昂贵设备，但防止事故的是细致的培训。

**训练句拆解**：we have learnt 为省略关系词的定语从句；that 引导表语从句；两处 it is … that 都强调主语，equipment/training 均按单数处理。

### 考场价值

删去两个 it is … that，分别得到“复杂技术得到宣传”“便宜技术改变世界”。句首分词的逻辑作者和语法主语并不完全匹配，理解原文时还原 I，仿写时主动消除悬垂。

## 重要单词

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| invention | 核心 | 发明；inventions 可数。 |
| sophisticated | 可能陌生 | 复杂精巧的，不宜一律译为世故的。 |
| enchantingly | 可能陌生 | 令人着迷地，修饰形容词。 |
| hype | 可能陌生 | 大肆宣传、炒作，通常不可数。 |
| cheap | 核心 | 便宜的，本句突出低成本，不是质量差。 |
| learn | 核心 | 领会、认识到；have learnt 表截至现在形成的认识。 |
