> Scientific publishing has long been a licence to print money.

## 句子拆解

### 断句

> Scientific publishing / has long been / a licence / to print money.

“/”分隔意群，“//”分隔同层并列分句或独立分句；方括号标出嵌入的从句或修饰部分。断句不改变原句成分之间的归属。

### 主干读法

Scientific publishing has been a licence to print money.

### 逐项分析

| 原句成分 | 结构、作用与内部关系 |
| --- | --- |
| Scientific publishing | Scientific 作定语修饰 publishing；publishing 是名词化的出版活动，整体为单数主语。 |
| has long been | has been 是现在完成时系动词，表示过去延续至今；long 为时间副词“长期以来”，不修饰 licence。 |
| a licence | a licence 为名词表语；不定冠词 a 把科学出版比作一项许可。 |
| to print money. | to print money 作 licence 的后置修饰，解释许可内容；print 为及物动词，money 为宾语。整个表达是习语，不是真有印钞权。 |

### 理解要点

语法骨架简单，难点是将 licence to print money 整体解码为“轻松获得丰厚利润的生意”。

## 句子直译

科学出版长期以来一直是一张“印钞许可证”，即一门轻松获得高额利润的生意。

## 原创拓展

以下两句为原创练习，不是历年试题原句。

### 迁移练习 1

> For the only shop near the gate, the new museum has been a licence to print money.

**练习要求**：给句子断句，标明主干与修饰关系，再作直译。

**参考答案**

断句：For the only shop near the gate, / the new museum / has been / a licence to print money.

**训练句直译**：对于门口附近唯一的商店而言，新博物馆一直是一个轻松获得厚利的机会。

**训练句拆解**：For 短语限定评价对象；museum 主语；has been 完成时；表语是比喻，不指博物馆印制纸币。

### 迁移练习 2

> Owning the only car park in the area was almost a licence to print money.

**练习要求**：给句子断句，标明主干与修饰关系，再作直译。

**参考答案**

断句：Owning the only car park in the area / was almost / a licence to print money.

**训练句直译**：拥有这个地区唯一的停车场，几乎就等于拿到了一张印钞许可证。

**训练句拆解**：Owning… 动名词短语作主语；only 修饰 car park；almost 限定比喻程度。

### 考场价值

把研究者无偿投稿审稿与商业出版商收费联系起来，才理解作者批评的利润结构。
