## 原句

> In a society that so persistently celebrates procreation, is it any wonder that admitting you regret having children is equivalent to admitting you support kitten- killing?

出处：2011年考研英语一阅读 Part A，Text 4，P3。[查看试卷原文](/files/english/exams/2011英一.pdf#page=5)。P 指文章自然段。

## 句子拆解

### 断句

> In a society / that so persistently celebrates procreation, / is it any wonder / that admitting / you regret having children / is equivalent to / admitting you support kitten- killing?

“/”标出主要成分与嵌入结构的边界；结合下表判断哪些成分处于同一层级。断句不改变原句词序，不要求逐块机械翻译。

### 主干读法

Is it any wonder that admitting regret is equivalent to admitting support for something cruel?

### 逐项分析

| 原句成分 | 语法作用 | 内部结构与理解 |
| --- | --- | --- |
| In a society ... | 背景状语 | in 表身处何种社会环境；a society 为介词宾语，后接限制性定语从句。 |
| that so persistently celebrates procreation | society 的定语从句 | that 指 society 并作主语，celebrates 为谓语，procreation 为宾语；persistently 修饰 celebrates，so 加强持续程度。celebrate 是公开赞颂，不只是举办庆典。 |
| is it any wonder that ... | 反问主句 | 一般疑问句语序，is 位于 it 之前；it 为形式主语，any wonder 为名词表语，后面的 that 从句说明真正被判断的情况。反问暗示不值得惊讶。 |
| that admitting you regret having children is equivalent ... | 后置主语从句 | that 只引出内容；整个从句的主语是 admitting you regret having children，谓语为 is equivalent to ...，不能把最近的 children 当主语。 |
| admitting you regret having children | 动名词主语内部 | admitting 为主语中心，后省去内容连接词 that；you 为内部主语，regret 为谓语，having children 为 -ing 宾语，指对已经生育这件事后悔。 |
| is equivalent to | 内容从句的系表 | is 为系动词，equivalent 为形容词表语，to 为介词，表示与……等同；后接 admitting 的动名词结构，不是 to do 不定式。 |
| admitting you support kitten-killing | to 的宾语及内部内容 | admitting 后也省 that；you 为内部主语，support 为谓语，kitten-killing 为复合名词宾语。原试卷行末连字符造成 kitten- killing 的提取间隔，按“杀害小猫”理解。 |

### 理解要点

反问揭示社会压力下的道德化评价，并非作者认为后悔育儿真的等同于伤害动物。两个 admitting 构成被比较的行为，regret having children 也不等于打算伤害孩子。

## 句子直译

在一个如此持续赞颂生育的社会里，承认自己后悔生了孩子，就等同于承认自己支持杀害小猫，这又有什么可惊讶的呢？

## 原创拓展

以下两句为原创练习，不是历年试题原句。请先独立断句，标出主干、从句与非谓语的作用，再作直译。

### 迁移练习 1

> In a workplace that constantly praises long hours, is it any wonder that admitting you need rest feels like admitting you lack commitment?

**参考答案**

断句：In a workplace / that constantly praises long hours, / is it any wonder / that admitting you need rest / feels like admitting you lack commitment?

**训练句直译**：在一个不断赞扬长时间工作的职场里，承认自己需要休息就像承认自己缺乏投入，这又有什么可惊讶的呢？

**训练句拆解**：that praises 是 workplace 的定语从句；wonder 后 that 为内容。两个 admitting 内部都省去 that，前者作主语，后者作 like 的宾语；这是评价压力的类比。

### 迁移练习 2

> Is it any surprise that questioning a popular rule is sometimes treated as questioning the whole organization?

**参考答案**

断句：Is it any surprise / that questioning a popular rule / is sometimes treated / as questioning the whole organization?

**训练句直译**：质疑一条流行的规定有时被当成质疑整个组织，这有什么可奇怪的呢？

**训练句拆解**：it 为形式主语，that 内容从句为真正判断对象。questioning rule 作从句主语，is treated 为被动，as 后第二个 questioning 表被归入的行为类别。

### 考场价值

反问揭示社会压力下的道德化评价，并非作者认为后悔育儿真的等同于伤害动物。两个 admitting 构成被比较的行为，regret having children 也不等于打算伤害孩子。
