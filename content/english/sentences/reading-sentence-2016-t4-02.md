## 原句

> But we’re going to have questions like that where we have things we’re doing that don’t make sense when the market changes and the world changes.

出处：2016年考研英语阅读 Part A，Text 4。[查看原文上下文](/files/english/exams/2016英一.pdf#page=5)。定位：所附试卷 PDF 第 5 页；本句原文已核对。

## 句子拆解

### 断句

> But we’re going to have questions like that / [where we have things / [we’re doing] / [that don’t make sense / when the market changes and the world changes]].

“/”划分意群；方括号标出从句或嵌套成分。断句用于辨认结构，不表示每处都必须停顿。

### 主干读法

**主干读法**：We are going to have questions where things we are doing do not make sense.

### 逐项分析

| 原句成分 | 语法作用与内部结构 |
| --- | --- |
| But we’re going to have questions like that | But 承上转折；we 为主语，are going to have 为将来谓语；questions 为宾语，like that 修饰 questions，指前述经营困境。 |
| [where we have things | where 引导情境性的定语从句，修饰 questions 所指处境；we have things 为内部主干。 |
| [we’re doing] | 省略宾语关系词的定语从句，修饰 things；we are doing sth，省掉的 sth 即 things。 |
| [that don’t make sense | 第二个定语从句也修饰 things；that 作主语，don’t make sense 表不再合理。 |
| when the market changes and the world changes]]. | when 引导时间/条件背景，修饰 don’t make sense；the market changes 与 the world changes 为 and 并列两小句。 |

### 理解要点

things 同时被 we’re doing 与 that don’t make sense 限定；最后 when 解释何时失去合理性。说话人从纸媒转型推及所有企业都可能遇到的变化。

## 句子直译

但我们也会遇到那样的问题：我们正在做的一些事情，在市场变化、世界变化时，会变得不再合理。

## 原创拓展

以下两句为原创练习，不是历年试题原句。建议先遮住参考答案完成断句与翻译。

### 迁移练习 1

> We may face situations where the methods we use no longer work when demand changes.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：We may face situations [where the methods [we use] no longer work / when demand changes].

**训练句直译**：我们可能面临这样的情况：当需求变化时，我们使用的方法不再奏效。

**训练句拆解**：situations 后 where 情境从句；we use 修饰 methods，省略宾语关系词；when 修饰 no longer work。

### 迁移练习 2

> The school has rules that teachers follow that make little sense when lessons move online.

请先断句，指出主干、从句或非谓语的作用，再直译。

**参考答案**

**断句**：The school / has rules [that teachers follow] [that make little sense / when lessons move online].

**训练句直译**：学校有一些教师遵循的规则，而这些规则在课程转为线上时就不太合理了。

**训练句拆解**：两个 that 从句都修饰 rules；第一个 that 作 follow 的宾语，第二个作 make 的主语。

### 考场价值

things 同时被 we’re doing 与 that don’t make sense 限定；最后 when 解释何时失去合理性。说话人从纸媒转型推及所有企业都可能遇到的变化。

## 重要单词

| 词语 | 类别 | 本句含义与用法 |
| --- | --- | --- |
| make sense | 核心 | 合理，有道理 |
| question | 核心 | 此处指问题、困境 |
| market | 核心 | 市场 |
| be going to | 核心 | 表示将来或预期 |
| thing | 核心 | 事情，things 在本句指正在进行的做法 |
